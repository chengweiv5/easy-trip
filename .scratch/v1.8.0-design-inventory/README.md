## 必须先修正的设计差异

1. **版本文件缺失与碎片化**
   1.5.0、1.7.0、1.8.0 的规范命名正式文件缺失；1.6.0 文件存在但本轮未完整回读。先解决当前依赖的 v1.8.0，不顺手重写所有已发布历史版本。

2. **旧主题入口已过时**
   当前首页右上角是 App 设置，主题从 App 设置进入。工作台更多仅包含“旅行设置 / 分享行程长图 / 返回我的旅行”；不能沿用旧主题、隐私入口布局。对应 N01、N07、W07、A01。

3. **搜索地图只覆盖单一状态**
   D18 仅一个收起态 frame，缺少完整状态对照。“我的位置”文字及圆点已经存在，不能误报完全缺失；其最终样式、结果计数、半屏/展开及异常状态仍需核验。对应 N03、N04、W06。

4. **现有金额能力缺少正式设计覆盖**
   应恢复行程/交通编辑金额、首页/日行程汇总以及费用丢失确认。保持“未填”和“0 元”不同，不在历史快照中加入 v1.9.0 的住宿、交通、景点、吃饭、购物、其它分类。对应 N01、W02、W03、I06、I07、F01、F02。

5. **App 设置、地图授权、版本更新只有非 Pencil 参考**
   现存 HTML/JPG 不满足正式原生设计源要求，应根据当前代码恢复到同一份版本文件。对应 N07–N09、A02、A03；系统授权和安装界面仅记录交接，不伪造为 App 页面。

6. **分享应采用 R4，每日地图加路线清单**
   不含分享日历；工作台日历保留。旧 R3 不能作为当前分享设计。当前 v1.4.0 Pencil 哈希与历史 R4 记录一致，但本轮尚未逐个回读其中画板。对应 N05、H01、H02。

7. **旧成功结果弹窗和源码定义不能机械转成页面**
   全部安排成功后当前流程自动收起，不应额外强制成功弹窗。部分旧 Composable 没有生产调用；`WorkspaceOverlay.Feedback` 有类型/渲染分支但未找到构造入口，暂不算已证实可达页面。详见清单 EX01–EX04。
