## 首稿方案与待确认假设

以下是本稿推荐方案，**不是用户已经确认的需求**。关于单选还是拆分多类曾提出可选澄清，但未收到答案；因此以推荐假设继续制作可回改的设计，没有进入实现。

1. 沿用既有费用来源：每个行程项保留一个金额，单选一个类别；交通路段固定归入“交通”。
2. 首页费用摘要、工作台更多菜单、单日及全程费用摘要都可进入统计。统计提供全程／单日范围、分类金额／占比／笔数及全部／分类明细。
3. 从明细回到原始费用编辑，不新增重复账目；返回保留范围、筛选和来源页面。
4. 旧交通费用可归交通；旧地点费用不按地点名猜类别，暂显示为“旧费用待分类”。这是迁移状态，不是第七类。
5. `已记总额 = 六类已分金额 + 旧费用待分类金额`。未填金额不算 0 元；已填 0 元计入笔数，全为零时占比显示 `—`。
6. 金额与分类一次保存，失败保留草稿且不改统计；金额已填但未选分类时不可保存；加载或读取失败不伪装成零费用。
7. 本轮不新增独立账本、多笔拆分、预算、AA、多币种或费用导出。

**进入实现前需评审的关键点：**是否接受每笔费用单选一类，以及旧地点费用逐笔补分类的处理。
