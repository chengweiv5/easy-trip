# v1.6.0 全局主题配色

Status: ready-for-agent
阶段：2026-09-23 用户确认设计，Android 实现完成，验证见 ../v1.6.0-theme-implementation/verification.md。

## 目标与范围

保留现有布局，为所有旅行提供湖畔晴空、松林晨光、落日陶土、山岚暮紫、玫瑰沙丘 5 套主题。默认湖畔晴空。交付可编辑 Pencil 画板、配色比较页、交互说明；设计已完成，按确认方案实现。

## 方案比较

推荐：独立主题页，点击预览后应用。可以在同一行程内容上比较配色，返回即可取消，状态边界明确。

备选：点击即保存，少一步操作，但比较主题会连续改变全局偏好。

备选：设置页下拉列表，占用空间少，但无法充分展示多角色配色与真实内容。

## 入口与页面

1. 首页右上角当前静态头像位置改为 48dp 调色盘按钮，语义为「主题配色」；空态也显示。
2. 工作台更多菜单添加同名项，副标题显示当前主题和「所有旅行」。旅行设置、分享行程长图、地图授权、返回我的旅行全部保留。菜单允许滚动，推荐最大高度 320dp；主题页返回时保留当前旅行、日期、抽屉高度、视图模式和滚动位置。
3. 页面包含返回、标题、效果预览、5 行单选列表和底部应用操作。行高至少 62dp，返回及应用目标至少 48dp；大字体与短屏时内容滚动，不缩小文字。底部操作位于安全区内。
4. 预览中的旅行内容为展示样例，预览卡不触发业务操作。选择项展示名称、风格、色样、描边和勾；「默认」标识表示升级和缺省选择，不代表当前已应用。

## 状态与行为

savedTheme 是本地持久选择，previewTheme 是主题页临时选择。

- 打开：previewTheme = savedTheme。应用按钮禁用，显示「已使用{主题}」。
- 点主题：只改变本页配色预览与选中状态。选择回当前已应用主题时，应用按钮重新禁用。
- 应用：先保存，再更新全局主题并返回来源页，提示「已切换为{主题}」。保存中显示「正在应用…」，禁用重复提交、选色、页面返回、系统返回和返回手势；成功或失败后恢复导航；保存操作不依赖网络。
- 返回：尚未应用时直接退出，丢弃临时预览；不改 savedTheme，不显示二次确认。
- 保存失败：留在主题页保留选色，提示「未能应用主题，请重试」，操作变为「重新应用{主题}」；全局继续保持原主题。
- 冷启动与升级：读取 savedTheme 后再展示主界面，避免先闪默认主题；首次使用或未知主题标识回落湖畔晴空。进程恢复时持久主题优先；主题页临时预览不要求跨进程保存。

## 颜色边界

- 跟随主题：首页主卡、背景、卡片、筛选、选中线、主题按钮、工作台控件、地点池、行程列表和日历的界面容器、设置、编辑浮层、提示容器。系统栏使用对应浅色背景和深色图标。
- 固定：地图 SDK 底图；每日路线及序号的 8 色共享日期色盘；危险操作与错误红色；备注强调保持现有语义。日期按钮的选中背景跟随主题，路线/序号的日期颜色不跟随。
- 长图：分享页操作区跟随主题；长图导出模板保持当前湖畔晴空规则，既有图片不变。
- 不增加深色/跟随系统模式、自定义颜色、主题商城、按旅行独立主题、账号同步或动态壁纸取色。

## 已确认的实现边界

- ThemeCatalog：保存稳定主题 ID、名称及完整颜色角色，固定语义色独立定义。
- ThemePreferenceStore：负责本地持久读取和写入，显式返回成功或失败。
- 应用主题入口：订阅已保存主题，提供 Compose 与自绘地图控件共用颜色；页面不各自保存主题。
- ThemePicker：管理临时预览、提交中与错误状态；预览使用局部主题，不提前覆盖应用主题。

## 验收

设计：五主题在同样内容下可比较；20 个新增画板可编辑；文字不溢出；30 组主要文本配色对比至少 4.5:1；主题不改变日期颜色语义。Pencil 原生保存后独立副本回读确认。

未来实现：逐个主题切换并重启；首页和工作台双入口；返回放弃；保存失败重试；短屏/字体放大；地图、地点池、行程、日历与浮层一致；业务数据和页面位置保持。
