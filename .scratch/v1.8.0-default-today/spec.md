# 行程默认选中当天

状态：DONE（2026-10-05，本地修复与验证完成；未提交、未推送、未安装物理手机）

## 问题与范围

原 v1.8.0 需求：进入行程时，如果设备当前日期处于旅行日期范围内，默认选中当天；否则默认选中第一天。
上一轮仅实现搜索返回地图，遗漏这一项。当前已安装包的默认逻辑只选择第一天，未使用 startDate 或当前日期。

## 规则

- 按设备本地时区的日历日期判断，不使用 UTC 日期。
- 首次进入旅行，日期范围含首尾两天；匹配 startDate + TripDay.index 的当天。
- 尚未开始、已经结束或未设置起始日期的旅行，默认第一天；没有旅行日时显示全程。
- 用户主动切换日期/全程后，切换地点池、从搜索返回、抽屉操作和相同页面状态恢复不覆盖其选择。
- 被选日期删除后沿用现有相邻日回退逻辑；重新从旅行列表进入时重新计算默认日期。
- 日期栏自动使选中项可见，不因重组或手动滚动反复跳回，不改变地图或抽屉布局。
- 不修改地图/抽屉外观，不改旅行日期和数据库，不更改排序、版本号或正式发布。
