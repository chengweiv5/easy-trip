## 范围

- 仅实现搜索返回地图，不扩展日期默认选中或结果排序。
- 输入联想仍留在搜索列表；已有当前查询结果时，明确点击“搜索”或键盘搜索才返回工作台。
- 键盘关闭、抽屉收起，保留原“地点池 / 行程”及当前天选中状态。
- 将本次结果作为临时图层显示：放大镜标记及名称；缺失/无效坐标不传给地图，并显示可定位数量。
- 返回地图时一次适配搜索地点；展开、半屏、收起或拖动抽屉仅覆盖地图，不更改相机或移动搜索摘要。地图不增加遮罩。
- 摘要提供关键词、结果数、列表和清除。列表返回原查询结果；清除只撤销临时图层，不更改收藏或行程。
- 点击搜索标记仍可打开原地点详情和收藏流程。
- 临时搜索范围按工作台/旅行隔离，并支持状态恢复；不存入收藏数据库。

- 搜索 ViewModel：自动搜索不退出、明确提交只退出一次、过期查询不返回地图。

- Compose 和导航：实际点击搜索/列表/清除；结果列表恢复；真实 Room 中收藏数量不变；抽屉覆盖时地图布局和请求保持。
