## 范围与画面

仅设计用户明确点击搜索按钮后返回地图的一个页面，不改日期选中、排序规则或搜索列表 UI。

沿用“湖畔晴空”配色、白色紧凑卡片、地图工作区，以及底部“地点池 / 行程”标签结构。示例为“西湖”及 6 个地点；底图、坐标、旅行和收藏数据均为设计示意。

- 地图以橙色放大镜标记搜索结果，配独立地点名称，避免与行程序号和收藏标记混淆。
- 地图视野容纳全部有效坐标结果，避让顶部旅行卡片、地图工具、搜索摘要和底部抽屉。
- 搜索摘要显示关键词、结果数、“列表”和清除入口。
- 抽屉默认收起；保持搜索前的“地点池 / 行程”选中项。本稿用“地点池”演示。
- 点击关键词或“列表”返回现有搜索页；本稿不重新设计该页面。
- 清除只移除临时搜索结果，不修改收藏或行程；搜索结果不自动加入地点池。
- 密集结果可使用聚合标记；本次 Pencil 主画面只展示 6 个展开的结果点。

## 图层结构

1 个 390 × 844 的手机画板，共 180 个原生图层：

- 89 个 frame
- 33 个 path
- 27 个 text
- 23 个 ellipse
- 5 个 rectangle

没有 browser 节点、图片填充、远程素材依赖或扁平截图替代。地图道路、地点图标、文字和面板可分别选择、编辑。
