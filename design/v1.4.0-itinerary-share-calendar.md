[打开 R3 交互稿](v1.4.0-itinerary-share-r3.html) · [可编辑画布](easy-trip-v1.4.0.pen) · [原 R2 设计说明](v1.4.0-itinerary-share.md)

## 版式与取舍

旅行标题与摘要 → 全程日历 → 各天日期、路线地图、行程清单、交通和备注 → 页脚。

日历沿用 v1.3 旅行日历的日期列、小时轴和每日配色。推荐每组并排 3 天，兼顾全程节奏与长图高度；超过 3 天向下续排，各组时间轴保持一致，最后不足 3 天可铺满剩余宽度。所有旅行日都必须输出，不能仅截取当前横向滚动视窗。

评审稿提供「2 天一组」对比：文字空间更宽，代价是长图更长；这只是设计对比控件，不增加产品设置。月历只能表达每天有无安排，不能表达停留和时间分布，因此本轮不采用。

输出宽度沿用现有长图 1080px。390px 设计基准下左右留白 20px，时间轴 32px，小时高度 48px；日历正文 10px、辅助时间 8.5–9px，输出等比放大。最上、最下时间刻度都完整保留。日期和站点编号同时表达所属日，颜色只是辅助。

## 内容与交互

- 默认分享全程，标题为「全程日历」。选一天后变为「当日日历」，保留原旅行日序号和该日范围；前日跨午夜延续进所选日的事件仍显示，并标明源日。
- 日历站点编号对应原日清单和每日地图，排序按时间显示，不能改变原行程顺序或去重重复到访。
- 正常时段显示编号、名称、起止时间。交通方式、时长、距离仍在下方相邻地点之间显示；日历空白不保证是自由时间。
- 关闭备注不改变日历、地图与时间补充，只隐藏下方备注。
- 预览、放大、保存与系统分享输出同一份内容。新增日历不增加开关或编辑入口。保存和分享在 HTML 中仅演示反馈。

## 时间与密集内容规则

| 场景 | 展示规则 |
| --- | --- |
| 无到达时间 | 放在该日期下的「待安排」，有已设时长则保留，不推断开始时刻。 |
| 有到达时间、无停留时长 | 时间轴上用虚线 60 分钟示意占位；编号配合网格下「时间补充」明确到达时间与停留待设，绝不显示推算的离开时间。占位只出现在来源日，接近午夜时在 24:00 截止，不投影到下一日，也不提示已发生跨日。 |
| 短停留、长名称、文字装不下 | 保持真实时段比例。卡片只显示编号，完整名称和起止时间放在该组网格下方；极短时段小于一个字高时只保留刻度，文字全部下移，不能增大时段冒充更长停留。 |
| 真实时段重叠 | 橙色合并区域标明原始编号及项目数，网格下完整列出每项名称与时间，不丢站点。 |
| 虚线占位挤在一起 | 标明「占位接近」，不能把未知时长断言为实际时间冲突。 |
| 跨午夜 | 仅对已知停留时长按午夜拆分可见时段；下一日标记「前日延续」并沿用源日编号，网格下写源日和完整起止。分组边界同样继续；不重复累计站点。 |
| 结束超出旅行日期 | 旅行最后一列截在 24:00，补充区写完整结束时间和「结束超出旅行日期」，不新增旅行日。 |
| 单日输出且事件结束于次日 | 保留完整起止时间，注明「结束超出本图所选日」。 |
| 旅行日期未设 | 显示第 N 天、日期待定；保留相对日和已知时刻，不虚构日期。 |
| 空白日 | 保留日期列，标「暂无安排」；下方保留该日标题与空状态，不插入空地图。 |
| 全部时间未定 | 仅显示日期与待安排清单，不画无数据的小时网格。 |

时间轴覆盖所选范围内全部可见时段，向整点取整；常规最小展示 3 小时、最大 00:00–24:00，各组一致。没有跨午夜时，不强制展示整天空白。时间补充按日、编号排列并自动换行，不能截断。密集块本身装不下编号和冲突提示时，仅保留色块/刻度，完整信息全部放到补充区。

## 生成与集成边界

沿用现有分享快照，日历布局读取与每日清单相同的旅行日、到访实例、到达时间、停留时长。日历绘制只负责静态排版；现有地图、长图文件生成、MediaStore 保存和 FileProvider 分享继续承担各自职责。读取与绘制不能修改旅行安排。

新增头部高度必须计入既有图片尺寸和内存预算。超过可生成上限，展示已有「行程过长，请选择一天」状态，不压小字号或静默截断。空旅行禁用保存/分享；有内容但时间未设仍允许输出。生成失败保留重试；打开系统面板不等于发送成功。

## 评审与验收

交互稿可切换 3 天/2 天密度、常规 3 天、7 天续排、边界时间、日期待定、全程/单日和备注。地图为设计示意；边界场景为检查排版刻意构造的安排。

本轮已通过设计复核与以下检查：日期完整续排、地图与编号对应、范围与备注联动、放大/返回、加载/空行程/失败/过长恢复、文字换行、页脚与边缘、颜色对比度。无 JavaScript 异常；390px 视口无横向溢出，常用配色对比度至少 4.83:1。Pencil 新增完整长图 `W7hF6d`、手机预览 `xC5Kc`、规则板 `s5HNQE`；完整长图与规则板无裁切，手机视窗有意滚动裁切。已原生保存并对同哈希磁盘副本回读，确认 R3 节点存在。HTML 与 Pencil 因字体、行高不同，高度略有差异，均为可编辑设计源。Android 实际日历导出待设计确认后开发和验证。
