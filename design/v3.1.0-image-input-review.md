## 本稿取舍

采用**输入框内的图片附件**，而非独立“识图模式”。支持纯图、纯文字、图文混合；文字输入不回退。

- 沿用当前搜索城市，可补充或更换；图片里明确写出的城市作为核对信息。
- 先选图、预览、移除和补充文字，再点击「全部标记到地图」直接开始处理。选图不触发发送。
- 图片、文字、图文混合均不弹发送确认；首次使用、后续发送或更换模型/端点均一致，不增加“始终允许”开关或一次性授权页。
- 复用现有候选、歧义核对、勾选、批量确认和回执，不直接写地点池。
- 不包含拍照、系统分享接收、网页抓取、应用内裁剪/涂抹、视频或长期图片库。
- 图片示例为Pencil原生图层，不使用真实用户照片或平台截图。

### 暂定数量与格式

以下为**本稿建议参数**，不是已验证的模型限制：

- 每批最多6张；JPG、PNG、WebP静态图。
- 单张不超过10MB，总计不超过30MB；文字最多2000字。
- 超限、不可读和不支持的文件逐项说明；合格附件保留，不静默截断。
- 解析仍最多20个地点；超过时保留完整素材，要求用户主动分批，不擅自只处理前20项。
- 6张时附件横向滚动，全部图片均可预览和移除；按选图顺序处理。

## 流程与异常

| 阶段 | 交互约束 |
|---|---|
| 选图 | 系统选择器只读取选中内容；取消不改变草稿。选择器画面为示意，不承诺各系统外观一致。 |
| 预览 | 完整图片可缩放检查；移除仅影响当前附件。含隐私时提示先在系统相册处理后重选。 |
| 点击发送 | 点击「全部标记到地图」即开始准备、发送和理解，不经过App内授权/确认弹窗。服务与数据去向采用非阻断说明；图片与文字规则相同。 |
| 本地准备 | 发送前进行编码、尺寸及元数据处理；压缩预算和可读性待实施验证。可见个人信息不会因移除元数据而消失。 |
| 进度 | 逐图显示准备/发送/理解，再显示地图查询阶段；不显示无法测量的百分比；禁用重复提交。 |
| 取消 | 旧请求回调不能覆盖草稿；素材及已完成内容保留。已发送部分无法撤回，不宣称取消等于未发送。 |
| 部分失败 | 成功结果保留，可只重试失败图片或先查看成功项；重试可能产生费用。 |
| 没有明确地点 | 换清晰图或补充文字；不凭风景外观猜位置，不编坐标。 |
| 模型不支持 | 已知不支持时发送前拦截；发送后被拒绝时如实说明，不能称“未发送”。保留草稿，不自动切换服务商。 |
| 地点核对 | 图号和原文可回看；同名、名称残缺、城市不明独立处理。重复POI合并并保留所有来源。 |
| 确认收藏 | 只保存明确勾选且属于当前旅行的地点；沿用候选分类及分类选择器，图片不擅自改分类。 |
| 草稿 | 当前旅行会话内收起可恢复，清空需确认。切换旅行/结束会话前提示处理；进程重启不承诺恢复原图，需明确重新选择。 |

截图文字只是输入资料，其中“忽略规则”“自动收藏”等内容不获得执行权限。坐标来自地图POI查询，不来自模型臆测。

### 设置与隐私

App全局「助手设置」原位增加图片能力状态。文字连接成功不等于图片可用；能力检查由用户主动点击后直接运行，不另弹授权。设置页常驻说明会发送内置示例图片至已配置服务及可能费用，不能暗用相册图片。

输入区常驻简短说明：点击即发送至已配置的模型，可能产生费用；仅处理本次所选图片、文字和必要城市。取消发送弹窗不代表选择素材后自动上传，也不取消收藏确认、清空草稿确认或操作系统权限流程。

原图不永久保存到地点池；原图、Base64、API Key不写入日志或普通备份。临时文件清理、异常退出残留与供应商保存政策需开发前验证。本稿不声称模型服务不留存数据。

### 布局与无障碍

- 沿用湖水绿主题、地图入口和标题；正文统一左右16dp。
- 上传/提交48dp，移除命中区44dp；来源条视觉高32dp、点击区至少44dp。
- 附件横滚、正文纵滚；键盘出现压缩地图，主操作在键盘上方。
- B14仅展示320dp主要字号换行；静态长画板不等于真实设备滚动或完整2倍系统字体测试。
- 地图字母只作关联，不是排名；状态用文字，不只依赖颜色。
