## 已确认的更新流程

手动检查 → 查看更新说明 → 下载 → 系统确认安装。

- 不自动下载，不强制更新，不在进入 App 时主动弹窗。
- 展示版本号、更新说明和安装包大小；下载可取消、失败可重试。
- 下载完成后交由 Android 系统确认安装；稍后安装或拒绝系统许可不影响继续使用。
- 只接受可信的正式发布，不将主分支提交当作已发布版本。
- 只升级、不降级；当前版本领先正式版时说明原因，不展示旧版下载按钮。
- 安装包需校验；不卸载当前 App、不主动清除旅行数据。
- 开发阶段仍须落实发布元数据与 versionCode 比较、可信包校验、系统安装许可及返回处理。

## 地图授权边界

- 高德地图服务授权不等于系统定位权限；打开设置时不申请定位权限。
- 只迁移入口，保留原有主题和地图授权值。
- 地图未授权时保留地图区域内的“查看并授权”就地引导。
- 阅读确认前不可授权；撤回前说明地图、在线地点搜索与路线服务将受影响。
- 撤回不删除已有旅行与收藏地点。
