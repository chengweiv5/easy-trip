# Easy Trip v2 交互与视觉升级设计

## 1. 目标

Easy Trip v2 在不改变 v1 本地优先数据模型和行程编排规则的前提下，提升旅行工作台的状态辨识度、地图浏览效率和每日行程可读性。

本版本聚焦：

1. 明确区分选中与未选中的控件；
2. 将搜索结果独立为一个内容 Tab；
3. 点击搜索结果后在地图中定位并高亮地点；
4. 支持标准、卫星、卫星路网三种地图图层；
5. 强化每日行程的卡片与交通连接结构；
6. 优化距离显示；
7. 自动适配地点池视野，同时保护用户手动调整的视角；
8. 提供正式的 Android adaptive app icon；
9. 固定地图、搜索和地图范围控制，仅让内容列表随抽屉收起。

## 2. 非目标

v2 不新增：

- 新的 Room 业务表或 schema 版本；
- 云同步、账号或多人协作；
- 自动生成或自动优化行程；
- 自定义地图落点；
- 实时导航；
- 新地图供应商。

## 3. 工作台信息架构

工作台从上到下固定为四层：

1. 顶部栏：返回、旅行名称、地图授权、旅行设置；
2. 地图区：高德地图、图层切换入口；
3. 固定控制区：搜索框，以及地点池、单日、全程地图范围；
4. 内容抽屉：搜索、地点池、每日行程三个 Tab 及当前 Tab 内容。

地图、搜索框和地图范围始终可见。内容抽屉支持收起、半屏和展开；收起后保留一个可见的“展开抽屉”入口。

输入或聚焦搜索框时自动切换到“搜索”Tab。切换内容 Tab 不隐式改变地图范围；用户可独立决定当前查看地点池、单日或全程地图。

## 4. 视觉状态语言

采用“实心选中”方案：

- 选中项使用主题强调色实心背景和高对比反白文字；
- 未选项使用透明背景、无描边和中性色文字；
- 禁止仅依赖细微颜色变化表达选中状态；
- 焦点、按压和禁用状态仍须保留 Material 可访问反馈；
- 选中状态同时通过语义属性暴露给辅助功能。

该规则统一应用于：

- 搜索、地点池、每日行程 Tab；
- 地点池、单日、全程地图范围；
- 标准、卫星、卫星路网图层；
- 地点标签筛选项。

## 5. 搜索体验

### 5.1 独立搜索 Tab

搜索结果不再附着在地点池列表下方。内容抽屉包含：

- 搜索：展示搜索状态、错误和候选 POI；
- 地点池：只展示已收藏地点和标签筛选；
- 每日行程：展示当前旅行日的编排。

顶部搜索框是唯一搜索输入。开始输入时自动切换到搜索 Tab；清空输入后保留搜索 Tab，但展示空态。

### 5.2 搜索结果地图联动

点击搜索结果项时：

1. 保持搜索 Tab 和当前结果列表；
2. 设置该 POI 为地图焦点；
3. 地图移动并缩放到该坐标；
4. 对应搜索 marker 使用高亮图标；
5. 点击其他搜索结果时替换焦点和高亮；
6. 搜索结果更新后，如果原焦点已不存在，则清除焦点。

地图焦点是瞬时工作台状态，不写入 Room。Activity 重建时可通过 `SavedStateHandle` 恢复 POI ID；若结果集中已无该 ID，则自动清除。

## 6. 地图图层

定义：

```kotlin
enum class MapLayer {
    STANDARD,
    SATELLITE,
    SATELLITE_ROAD,
}
```

行为：

- `STANDARD`：标准城市地图；
- `SATELLITE`：卫星底图，不显示道路覆盖层；
- `SATELLITE_ROAD`：卫星底图并显示道路覆盖层；
- 用户选择写入应用级本地偏好，不绑定旅行；
- 切换旅行、Activity 重建或 App 重启后继续使用上次选择；
- 图层变化只更新现有 MapView，不重建 MapView。

偏好使用轻量本地键值存储，不新增数据库表。

## 7. 地图视野与标记

### 7.1 自动适配规则

工作台进入后默认范围为地点池，并自动把全部收藏地点纳入可视区域。

触发自动适配：

- 首次进入旅行工作台；
- 收藏地点集合发生增加、删除或坐标变化；
- 用户主动切换地图范围；
- 用户点击搜索结果，执行单点聚焦缩放。

不触发自动适配：

- 内容 Tab 切换；
- 抽屉收起、半屏或展开；
- 路线状态或文字信息变化；
- 与地图模型无关的普通重组。

地图命令通过单调递增的 viewport request ID 表达。Map host 仅在收到新 ID 时移动相机，避免重组重复执行。

### 7.2 搜索结果与选中标记

地图模型区分：

- 已收藏地点 marker；
- 搜索结果 marker；
- 行程顺序 marker；
- 当前聚焦的高亮 marker。

搜索层独立叠加在地点池、单日和全程范围之上。高亮不能只靠颜色表达，应同时改变图标尺寸、形状或中心符号。

### 7.3 重复地点

单日和全程范围继续按坐标合并 marker，但保留全部 occurrence。标记文本显示顺序；点击后展示每次安排的日期、顺序和地点名称。

## 8. 每日行程卡片时间轴

每日行程采用交错结构：

```text
地点卡片
交通连接段
地点卡片
交通连接段
地点卡片
```

地点卡片显示：

- 大号顺序编号；
- 地点名称和地址；
- 可选到达时间和停留时长；
- 时间、跨日移动、删除操作；
- 拖动中的抬升、强调背景和阴影。

交通连接段显示：

- 交通方式；
- 格式化距离；
- 预计耗时；
- 等待联网、等待计算、计算中、成功或失败状态；
- 交通方式覆盖和失败重试操作。

连接段不参与拖动；其位置由相邻两个 item ID 决定。拖动期间只改变本地卡片顺序和连接段展示，松手后调用一次 repository。

## 9. 距离格式

定义纯函数：

```kotlin
fun formatDistance(meters: Int): String
```

规则：

- 小于 1000 米：显示整数米，例如 `850 米`；
- 大于或等于 1000 米：显示公里，最多一位小数，例如 `1 公里`、`1.2 公里`；
- 不显示无意义的 `.0`；
- 负值视为无效输入，不进入 UI。

预计耗时继续以适合阅读的分钟或小时分钟形式显示，不伪造缺失值。

## 10. App 图标

采用“地图定位点 + 路线”方向：

- adaptive icon foreground：简化定位点与弯曲路线；
- adaptive icon background：应用主题青蓝色；
- monochrome：单色轮廓，支持 Android 13 主题图标；
- 不包含文字；
- 在 launcher 小尺寸及圆形、方圆形 mask 下均保持可辨认。

需提供 `mipmap-anydpi-v26` adaptive icon XML、foreground/background drawable 和 manifest 图标声明。

## 11. 架构调整

### 11.1 状态所有权

`TripWorkspaceViewModel` 继续作为工作台导航状态的唯一来源，持有：

- 当前内容 Tab；
- 当前地图范围；
- 当前选中旅行日；
- 抽屉状态；
- 当前搜索焦点 POI；
- 地图 viewport request。

`PlacePoolViewModel` 负责搜索、收藏和筛选；将搜索结果及点击事件暴露给工作台。

`DayItineraryViewModel` 负责行程编辑，但选中日期由工作台状态驱动，避免双重状态源。

### 11.2 地图边界

扩展 `AmapMapHost`，接收：

- `MapUiModel`；
- `MapLayer`；
- 可选 viewport request；
- marker 点击回调。

host 内部增量处理图层和 viewport 命令。相同模型的普通重组不得清空覆盖物或移动相机。

### 11.3 数据边界

不修改 Room schema。地图图层使用应用偏好存储；搜索焦点与工作台导航状态使用 `SavedStateHandle`。POI 与路线仍通过现有高德适配器访问，上层不依赖高德返回模型。

## 12. 错误与边界行为

- 未授权：地图显示授权提示，地点池和每日行程仍可使用；搜索 Tab 显示需授权状态；
- 离线：搜索不可用，已有地点和行程可编辑，地图可显示本地数据与缓存路线；
- 空地点池：地图保持默认城市视野，不执行空 bounds 更新；
- 单个地点：使用固定合理缩放级别聚焦；
- 多个地点：使用带边距 bounds；
- 搜索结果缺坐标：不生成 marker，列表仍可显示并说明无法定位；
- 地图图层切换失败：保留当前图层并展示非阻塞错误；
- 旋转、重组、Tab 或抽屉变化不得重建 MapView。

## 13. 测试策略

### JVM 测试

- 选中/未选中状态模型；
- 距离格式边界：0、999、1000、1050、10000 米；
- 三种地图图层持久化；
- 搜索点击生成唯一 focus request；
- 首次进入、地点集合变化、范围切换生成新 viewport request；
- 普通 Tab/sheet 变化不生成 viewport request；
- 同坐标 occurrence 不丢失；
- 八色 palette 与第九日循环。

### Compose instrumentation

- 搜索输入自动切换搜索 Tab；
- 搜索结果不出现在地点池 Tab；
- 点击搜索结果触发地图聚焦和 marker 高亮；
- 三种内容 Tab 与三种地图范围的选中状态明确；
- 未选控件无边框；
- 行程卡片与交通连接段交错显示；
- 连续拖动只在松手提交一次；
- 抽屉收起后固定搜索与范围控制仍可见。

### 地图与真机验证

- 标准、卫星、卫星路网切换正确；
- 图层选择跨旅行和重启保留；
- 首次进入和地点变化自动适配；
- 用户缩放后切换 Tab/抽屉不重置视角；
- 搜索 marker 聚焦与高亮清晰；
- 30 个 marker、7 天路线下操作流畅；
- adaptive icon 在系统 launcher 和 Android 13 主题图标中显示正确。

## 14. 验收标准

1. 所有待选按钮无边框、无彩色底，选中状态使用唯一实心强调样式；
2. 工作台内容区包含搜索、地点池、每日行程三个独立 Tab；
3. 点击搜索结果后地图聚焦并高亮对应 marker；
4. 标准、卫星、卫星路网可切换且全局持久化；
5. 地图始终在顶部，搜索框和地图范围始终位于抽屉之上且可见；
6. 进入工作台和地点池变化时自动适配全部地点；普通重组不重置视角；
7. 每日行程呈现为地点卡片与交通连接段组成的时间轴；
8. 距离按米/公里规则显示；
9. App 使用定位点与路线主题 adaptive icon；
10. 单元测试、lint、instrumentation 和指定真机检查全部通过。
