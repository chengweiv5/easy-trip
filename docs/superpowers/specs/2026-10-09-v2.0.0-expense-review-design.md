## 用户已确认的边界

1. 花费具有独立入口，可跨旅行按历年、年度、月度回顾。
2. 每笔费用归入对应的旅行日；跨年、跨月旅行按各笔费用的所属日期分别归集。
3. 没有旅行日期的费用单列“未确定日期”，包含在全部汇总和原旅行中，不计入任何已确定年月。
4. 补记历史旅行的费用归入那次旅行的日期，而非补录当月。
5. 不新增预付、实付、付款日期或支付状态；统一称“已记录花费”。
6. 继续支持住宿、交通、景点、吃饭、购物、其它，以及同一行程地点多笔费用。

## 信息架构选择

比较三个方案：

- 只在旅行首页增加一个统计按钮：改动小，但跨旅行回顾仍是附属功能，不足以体现用户要求的重要性。
- **旅行／花费两个一级目的地（推荐，本稿采用）**：旅行负责计划、记录和单次回顾；花费负责跨旅行聚合。设置保留原入口，不虚构第三个模块。
- 独立通用账本：需要脱离行程的记账、付款等新模型，超出本轮需求，不采用。

本稿采用底部“旅行／花费”切换；只在两个一级目的地显示。进入旅行工作台、费用明细、年份选择等下级页面时使用返回导航，避免与工作台原有导航混淆。

- 启动仍进入旅行，不改变原默认启动行为。
- 初次打开花费进入当前年度；用户切换到往年后，当前会话内保留选择和滚动位置。
- 从明细进入原旅行或编辑一笔费用，返回时保留原年份、月份和分类；保存后重新计算同一范围。
- 不在花费页新增独立“记一笔”；继续进入具体旅行、旅行日、地点或路段录入，不新增无来源费用。

## 页面与交互

### I11–I20 编辑地点内联费用

- 编辑地点不再先进入费用列表。默认在同一页展示金额输入、住宿／交通／景点／吃饭／购物／其它六类快捷选择，以及按需展开的费用备注。
- 没有费用时，金额、类别和备注均为空；全空行不生成记录。用户明确输入 `0` 并选择类别时，创建一笔有效的零元记录。
- 已有一笔时，在原位显示并编辑这笔记录。点击“＋再记一笔”后，已有记录收起为摘要，新空白行在同页展开并聚焦金额。
- 已有多笔时，显示逐笔类别、备注、金额和草稿合计；同类别可重复。任一时刻最多展开一笔，点击其它记录切换展开项。
- 默认最多展示三笔；记录更多时通过“查看全部”在当前编辑页展开，并可收起。该操作不进入已保存费用列表，也不提前持久化草稿。
- 地点时间、停留时长、地点备注以及费用的新增、修改、移除共享一份草稿。底部“保存”一次性提交全部变化；取消、返回或手势退出时，若有改动，确认后整份放弃。
- 保存采用原子语义：成功后统一刷新地点、旅行统计和年月回顾；失败时所有草稿仍在、已保存数据完全不变，不允许出现地点失败但部分费用已生效。
- 移除已有费用只在草稿中标记，并提供撤销；保存后才删除对应费用 ID，取消则恢复原记录。移除新建未保存行不影响已有数据。
- 半填行不能静默丢弃。类别、金额或费用备注任一已填时，必须补齐类别与金额或移除该笔；非法格式、负数、超过两位小数或合计溢出时禁用保存并定位首个错误。
- 数字键盘出现时，表单内容可滚动，统一保存区固定在键盘上方；“完成”只收起键盘，不保存。
- 原时间滚轮能力不删除。主页面默认使用紧凑时间摘要，点击后展开原上午／下午、时、分、停留时长和“待定”状态；收起不会保存或丢失费用草稿。
- 从全局花费、旅行费用或分类明细进入某一条**已保存费用**时，仍采用独立单笔编辑：只更新该费用 ID，不涉及地点编辑草稿。旧的独立“新增费用”页面已停用并移入历史材料。

### R01 年度回顾

- 默认当前年；提供前一年、后一年、年份选择及“历年”入口。
- 展示年度已记录总额、记录笔数、有费用记录的旅行数。
- 12 个月按上下两排各 6 个月展示，柱状图与月份标签属于同一个点击单元；点击进入该月。
- 六类金额、笔数和占比；有旧费用时增加“待分类旧费用”独立提醒，不作为第七个正式类别。
- 按旅行展示**本年度部分**的金额；跨年旅行明确标注“本年部分”，不能显示全程金额冒充年度贡献。
- 固定说明：仅统计已记录费用；未记录不等于没有花费。旅行的“待出行／已出行”手动标记不改变费用日期归属，也不筛掉已有记录。
- “未确定日期”显示单独入口及金额，明确不包含在年度总额中。

### R02 历年回顾与年份选择

- 历年页展示全部已记录总额、年份列表、各年金额，以及单列的未确定日期金额。
- 全部金额 = 各年份金额之和 + 未确定日期金额。
- 跨年旅行在两个年度中均可出现，但全部范围的旅行数按稳定 tripId 去重；金额按费用记录去重。
- 年份列表可进入年度页；年度选择器提供当前年、存在记录的历史年份及逐年导航，无记录年份也能查看空状态。
- 本轮不做同比百分比、预算或花费预测，避免把记录覆盖不足误当实际消费变化。

### R03 月度回顾

- 展示选中年月、该月已记录总额、类别和旅行贡献。
- 跨月旅行只显示该月部分，返回年度时仍停留原年度。
- 本月没有费用时显示“这个月尚无费用记录”，不是“本月没有花费”。

### R04 分类明细

- 年／月范围和类别明确显示；列出范围内的所有相关费用，按旅行分组，行内标明日期、地点／路段和备注。
- 同地点同类别的多笔费用分别显示；逐笔进入既有编辑流程。
- 不把分类小计、旅行汇总或已展开的费用再次计入总额。
- 旧待分类记录可沿用既有补分类流程；补分类仅改变分类小计，不改变年月和全部总额。

### R05 旅行贡献与全程

- 从年度旅行贡献进入时，默认显示本年度部分。
- 跨年旅行同时提示本年度与全程金额；切到“全程”需明确告知统计范围改变。
- 返回年度页不带回全程范围，不污染上一级金额。

### R06 未确定日期

- 展示所有未定日期旅行的费用、总额、笔数和待分类提醒。
- “设置旅行日期”进入已有旅行设置，不引入独立费用日期字段。
- 保存有效旅行日期后，费用按其行程日进入对应年月；失败保留未确定日期归属。
- 不猜年份，不按录入时间归集，也不要求先设置日期才能在原旅行中记账。

### R07 日期变更与删除影响

- 旅行开始日期改变、旅行日重排、费用所在行程项跨日移动，都可能改变年月归属；金额和原费用 ID 不变。
- 跨月／跨年变化时，确认界面显示变更前后归属及受影响金额；同月移动沿用现有行程确认。
- 单笔编辑、删除，或删除地点／旅行日／旅行，成功后同步刷新所有受影响范围。
- 不新增“删除旅行但保留独立账本”的语义。删除仍遵守现有级联影响确认，明确提示会从年月统计中移除的费用；失败不扣减。
- 跨日住宿整笔计入记录所在日，不自动摊分；用户可按天分别录入。
- 路段费用仍为现有单金额、固定交通分类，归入其路线所属旅行日；不顺带扩展路段多笔。

## 空值、错误与一致性

- 无记录：显示“尚无费用记录”和“—”，不显示伪造的 0 元、笔数或占比。
- 已记录 0 元：显示 `¥0.00 / 1笔` 等真实记录数；占比显示“—”，总额为 0 时不除以 0。
- 加载与读取失败：不先渲染假 0；失败可重试，保留选中的时间范围。
- 读取结果为一致快照；编辑或日期修改成功后刷新，不能混合旧分项和新总额。
- 求和使用分；沿用既有负数、精度和溢出校验。聚合溢出时显示无法统计并保留数据，不截断或回绕金额。
- 金额与笔数可读，不只依赖柱状图颜色；窄屏、大字体时正文可滚动，选择与返回动作可达。
- 设计画板展示完整滚动内容，不把超出实体手机高度的内容当作溢出裁切。
