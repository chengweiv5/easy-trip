# Easy Trip 旅行入口与创建 UI 收敛设计

## 1. 目标

将旅行入口与创建页面族收敛到 `design/easy-trip-v1.0.pen` 的 Forest Sage 视觉语言，并保持现有 Room、状态机和导航语义不变，形成可独立自动化验收和真机验收的完整入口闭环：

```text
旅行列表 / 空态
→ 创建旅行
→ 创建成功进入工作台
→ 返回旅行列表
→ 再次进入旅行
→ 删除旅行
→ 列表刷新 / 空态
```

本批覆盖 Pencil 场景 01、01v、07、09、13、36、47，以及列表加载/错误、创建提交中/失败等组合状态。

## 2. 范围

### 2.1 包含

- 我的旅行默认态、空态、加载态、读取失败与重试。
- 主旅行卡片和其他旅行列表。
- 创建旅行默认态、校验错误、提交中、提交失败与重试。
- 开始日期选择和由天数计算结束日期的现有语义。
- 创建成功后一次性进入新旅行工作台。
- 从工作台返回后恢复列表，再次进入已有旅行。
- 旅行删除确认、精确影响摘要、处理中锁定、失败恢复与列表刷新。
- 页面族内的窄屏、大字体、IME、长旅行名和关键操作可达性。
- 独立自动化验收记录、视觉冲突清单和 Mate 60 Pro 主路径验收结果。

### 2.2 排除

- Profile / 个人中心产品定义和新导航目的地。
- 旅行设置页中的日期范围修改、缩短日期影响和删除旅行日。
- 地图隐私、定位权限和系统设置引导。
- 工作台、搜索/地点和行程内容内部 UI。
- Room schema、旅行日期领域模型和创建命令重构。
- 为贴合静态稿伪造头像资料、旅行统计或不存在的业务能力。
- 横屏、分屏和全应用响应式专项；本批只修复入口与创建页面族的阻断性裁切和不可操作问题。

## 5. 我的旅行

### 5.1 页面骨架

- 使用 `WindowInsets` 处理状态栏和系统导航栏。
- 页面背景始终为 Forest Sage 背景色。
- 顶部视觉高度参考 62dp，标题左对齐。
- 右上角头像保留设计稿外观，但仅作装饰：
  - 不可点击；
  - 不声明 Button 角色；
  - 不提供虚假的 Profile content description；
  - 不触发设置或空回调。
- Loading、Empty、Error、Content 共用同一页头和内容边界，状态切换不造成明显整体跳动。

### 5.2 有数据状态

最近使用或当前主要旅行显示为主旅行卡：

- 白色表面、20dp 圆角、20dp 内边距。
- 旅行名使用 26sp 标题样式，长名称最多两行并省略。
- 日期、旅行天数和状态使用弱化信息层级。
- 主操作“继续规划”使用 48dp 绿色按钮。
- 整卡或明确主操作进入该旅行工作台；避免出现两个语义相同的进入入口。
- 设置与删除收进 `···` 菜单，降低视觉权重。
- 菜单绑定当前旅行，包含：
  - 设置；
  - 删除。
- 删除项使用危险色，菜单状态只属于当前卡片，并以旅行 ID 作为稳定身份。

其他旅行使用紧凑列表卡：

- 12dp 圆角。
- 显示旅行名、日期摘要和进入箭头。
- 名称与摘要允许换行或省略，不压缩字体。
- 整行点击进入对应工作台。
- `···` 菜单同样包含设置和删除，并绑定当前旅行。

页面级“创建旅行”入口保持明显，但不与主旅行卡的“继续规划”争夺同一层级。

### 5.3 空态

- 不再使用固定 `647.dp` 页面高度。
- 使用剩余可用空间内的约束驱动居中布局。
- 插画约 96–120dp，并允许在高度不足时随内容滚动，而不是裁切关键按钮。
- 文案：
  - 标题：“开始规划一次旅行”
  - 说明：“创建旅行后，可以收藏地点并按天安排行程”
  - 主按钮：“创建旅行”
- 主按钮在窄屏和大字体下保持完整可点击。

### 5.4 加载与错误

- Loading 保留页头，内容区显示稳定的加载状态。
- 读取失败保留页头和“创建旅行”能力。
- 错误信息明确，不只使用颜色。
- 提供“重试”操作；重复重试不创建重复 collector。

## 6. 创建旅行

### 6.1 表单结构

表单保持现有领域模型：

```text
旅行名称 + 开始日期 + 天数 + 出行方式
```

不改为日期范围模型，也不在本批新增结束日期编辑。

页面结构：

1. 44dp 返回操作。
2. 26sp 创建旅行标题。
3. 旅行名称输入。
4. 开始日期入口及计算后的结束日期摘要。
5. 旅行天数输入。
6. 出行方式选择。
7. Planning Tip。
8. 错误摘要和 48dp 提交按钮。

页面内容可纵向滚动，并使用 IME inset；键盘出现、字段错误展开或字体变大时，当前字段和提交按钮仍可到达。

### 6.2 字段

旅行名称：

- 高度 52dp。
- 默认白色表面、主色 2dp 描边、10dp 圆角。
- 错误时改为危险色 2dp 描边，并在字段附近显示文字错误。

日期入口：

- 高度 66dp。
- 展示开始日期和按天数计算的结束日期。
- 使用标准 Material DatePicker，但应用 Forest Sage 主题。
- 日期清除或错误不能静默改变已有有效草稿。

旅行天数：

- 与日期摘要同步。
- 继续使用现有合法范围和校验规则。
- 不因视觉收敛改变旅行日生成逻辑。

出行方式：

- 使用紧凑选择控件。
- 必须同时用文字和选中样式表达当前值。
- 不新增独立选择页面。

Planning Tip：

- 柔和绿色表面。
- 10dp 圆角、11dp × 12dp 内边距。
- 文案可换行，不抢占表单主层级。

### 6.3 校验和提交

- 字段错误就近显示，不能只变描边颜色。
- 提交中锁定返回、字段、日期选择、天数、出行方式和提交按钮。
- 提交中显示明确进度，不允许重复请求。
- 提交失败在按钮上方显示错误，完整保留草稿。
- 用户修改字段或重试后，旧异步 completion 不得关闭新页面或覆盖新错误。
- 创建成功只发布一次导航 effect，打开新旅行工作台。
- 进程恢复不得重复创建旅行或重复导航。

## 7. 删除旅行

- 从旅行卡 `···` 菜单进入共享危险确认弹窗。
- 确认内容展示现有精确影响摘要，包括将删除和保留的数据范围。
- 取消无副作用。
- 查询或删除处理中禁用确认、取消、Back 和外部 dismiss。
- 重复确认只执行一次删除。
- 删除失败保留确认内容和错误，可原地重试。
- 删除成功后由 Room 数据流刷新列表。
- 删除最后一个旅行后进入空态。
- 不在 UI 层手动移除旅行卡，不增加第二套列表真相。

## 8. 状态与组件边界

### 8.1 TripListViewModel

继续作为以下状态的唯一业务来源：

- Loading / Empty / Content / Error。
- 当前主旅行和其他旅行映射。
- 删除影响、确认、busy、失败和重试。

UI 不直接访问 Repository，也不本地推演删除结果。

### 8.2 CreateTripViewModel

继续负责：

- 表单草稿和 SavedState。
- 字段校验。
- 提交锁。
- request identity / stale completion 防护。
- 一次性成功导航 effect。

### 8.3 UI 组件

组件只接收状态和 action：

- `TripListContent`
- 主旅行卡
- 其他旅行行
- 列表空态 / 加载 / 错误
- `CreateTripContent`
- 日期入口
- 删除确认

如果现有文件职责过重，可按上述视觉单元做小范围拆分；不引入新业务抽象或兼容层。

## 9. 导航契约

- 旅行列表“创建旅行”进入创建页。
- 创建页顶部返回和系统 Back 使用同一规则。
- 提交中返回被锁定。
- 创建成功只打开一次新旅行工作台。
- 工作台返回后恢复旅行列表，不重复创建或导航。
- 点击已有旅行进入对应工作台。
- 删除成功停留在列表；删除最后一个旅行后显示空态。
- 头像不参与导航。

## 10. 错误与恢复

- 列表读取失败：显示错误和重试，同时保留创建入口。
- 创建校验失败：字段就近反馈，保留其他合法输入。
- 创建提交失败：保留完整草稿，允许原地重试。
- 删除影响查询失败：保留删除目标和错误，允许重试。
- 删除提交失败：保留确认状态和影响摘要，允许重试。
- 异步状态必须绑定请求和实体身份，旧 completion 不得覆盖新目标。
- `CancellationException` 必须继续抛出。

## 11. 自动化验收

### 11.1 JVM

- 列表 Loading / Empty / Content / Error 映射。
- 主旅行和其他旅行变化不产生陈旧卡片。
- 删除影响、取消、重复确认、失败恢复和旧 completion 防护。
- 创建字段校验、重复提交、失败保留草稿、稳定重试。
- 创建成功导航 effect 只发布一次。
- SavedState 恢复不重复创建或导航。

### 11.2 Compose

- 主旅行卡与其他旅行的视觉层级和语义。
- `···` 菜单绑定当前旅行，只有设置和删除。
- 头像无点击和 Button 语义。
- 空态使用约束驱动布局。
- 48dp 主按钮、44dp 页面图标操作和 40dp 卡片辅助操作。
- 长旅行名、窄屏、大字体、IME 下关键内容可达。
- 表单错误同时有文字反馈。
- 提交中所有变更和关闭入口被锁定。
- 删除中确认、取消、Back 和外部 dismiss 被锁定。

### 11.3 Room 与导航

```text
空列表
→ 创建旅行
→ 新旅行工作台
→ 返回列表
→ 再次进入同一旅行
→ 删除旅行
→ 列表刷新 / 空态
```

验证持久化、导航次数和列表数据一致性。

### 11.4 批次门禁

阻断条件：

- 功能或状态错误。
- 数据不一致。
- 崩溃。
- 流程不可达。
- 严重裁切。
- 关键交互失效。

不阻断条件：

- 细小间距差异。
- 字体渲染差异。
- 轻微圆角或图标像素差异。

这些差异记录到最终物理设备验收清单。

## 12. 真机验收

目标设备：Mate 60 Pro。

主路径：

1. 无旅行空态。
2. 打开创建页。
3. 触发表单错误。
4. 填写名称、日期、天数和出行方式。
5. 创建并进入工作台。
6. 返回列表并再次打开旅行。
7. 打开旅行菜单并删除。
8. 删除最后一个旅行后返回空态。

检查：

- 系统栏与安全区。
- 长名称和日期摘要。
- 键盘遮挡与滚动。
- 主按钮、菜单和返回操作。
- 删除确认和错误反馈。
- Forest Sage 色彩和视觉层级。

若本批未执行物理设备验收，验收记录必须明确标记 `DEFERRED`，不得用模拟器截图替代。
