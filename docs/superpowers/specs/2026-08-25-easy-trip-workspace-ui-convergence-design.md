# Easy Trip 工作台 UI 收敛设计

日期：2026-08-25

## 1. 目标

以 `design/easy-trip-design-formula.md`、`design/easy-trip-v1.0.pen` 和用户确认的 Mate 60 Pro 比例稿为视觉基线，收敛旅行工作台的地图、顶部控制区、搜索入口、地图控件、普通 Tab 和三档 BottomSheet。

本阶段只调整视觉结构、布局规则和共享组件边界。现有业务状态机、导航语义、数据模型、权限流程和 47 场景行为契约保持不变。

## 2. 已确认方案

采用“壳层优先”：

1. 先统一工作台共享壳层。
2. 再收敛地点池和行程内部内容。
3. 无争议视觉偏差直接修复。
4. 涉及产品语义、缺失数据或交互取舍的差异保留现状并登记为待讨论项。
5. 不按 47 个场景逐屏打补丁，不把 390×844 或 1260×2720 的固定像素写入生产布局。

## 3. 设计基线

### 3.1 来源优先级

发生冲突时按以下顺序判断：

1. 用户已确认的产品规则和本设计。
2. `design/easy-trip-design-formula.md`。
3. `design/easy-trip-v1.0.pen`。
4. 最新产品规格。
5. 旧 TODO 和当前代码视觉实现。

无法按此优先级消解且会改变产品语义、流程可达性或数据行为的冲突不得自行处理，必须进入待讨论清单。

### 3.2 视觉语言

采用 Easy Trip Forest Sage 体系：

- 背景：`#F5F3EE`
- Surface：`#FFFFFF`
- Soft Surface：`#E7EFE2`
- Primary：`#2D5E3A`
- Primary Dark：`#1B3A28`
- Secondary：`#4A6B52`
- Muted：`#6E7F72`
- Border：`#D6DDD0`
- Accent：`#D96F3B`
- Danger：`#BA1A1A`
- 标题字体：Funnel Sans
- 正文字体：Inter

业务页面只消费主题语义，不复制品牌色值或建立页面私有色板。

## 4. 工作台结构

```text
Workspace
├── Persistent Map
│   ├── markers / route
│   └── loading / degraded state
├── Top Overlay
│   ├── WorkspaceTopBar
│   ├── WorkspaceSearchBar
│   └── WorkspaceMapControls / MapLegend
└── WorkspaceBottomSheet
    ├── drag handle
    ├── WorkspaceTabs
    └── place pool / itinerary content
```

地图、顶部浮层和 BottomSheet 由同一个壳层协调。地点池和行程内容不能自行决定地图浮层位置或重复添加页面级水平边距。

## 5. 组件边界

### 5.1 WorkspaceScaffold

职责：

- 承载常驻地图。
- 计算安全区内的可用窗口。
- 协调顶部栏、搜索、图例、地图控件和 Sheet 的空间关系。
- 向浮层提供 Sheet 的实际可见边界。

非职责：

- 不持有地点池或行程业务状态。
- 不改变 Tab、搜索或地图操作的业务回调。

### 5.2 WorkspaceTopBar

- 使用浮动 Surface。
- 设计目标为约 52dp 的视觉高度、16dp 圆角和轻阴影。
- 返回与更多操作使用 20–22dp 图标。
- 主要操作触控区为 44dp。
- 标题过长时单行省略；日期保持可见；两侧操作不被挤压。

### 5.3 WorkspaceSearchBar

- 工作台只保留一套搜索入口视觉实现。
- 设计目标为约 46dp 高、23dp 圆角、白色 Surface 和轻阴影。
- 保留现有导航、搜索返回语义和 test tag。
- 搜索入口随 Sheet 的实际位置避让。

### 5.4 WorkspaceMapControls

- 图层、定位和缩放操作统一视觉语言。
- 密集地图控件使用 20–22dp 图标和 40dp 触控区。
- 搜索、返回、更多等主要操作使用 44dp 触控区。
- 独立主按钮和危险操作保持 48dp。
- 相邻触控区不得重叠，间距至少 4dp。
- 文字“定位”“关闭”、字符 `✓` 等占位表达改为规范图标，并保留 `contentDescription` 和选中语义。
- 图层菜单设置合理最大宽度，避免随父布局横向铺满。

### 5.5 WorkspaceBottomSheet

- 保留 `COLLAPSED / HALF / EXPANDED` 三档状态及现有状态转换语义。
- 使用 24dp 上圆角和统一上向阴影。
- 内容 padding 以设计稿的 `10/20/20` 结构为目标。
- 手势阈值必须由 dp 转换为 px，不能直接将原始 pointer px 与常量比较。
- 拖动位移限制在合法锚点范围内。
- 折叠态需保留可可靠拖动的操作区域，但不强制所有密集控件采用 48dp。
- 半屏和展开高度从当前窗口、安全区及内容约束计算，不写死 Mate 60 Pro 像素值。

### 5.6 WorkspaceTabs

- 使用普通文字 Tab，不使用胶囊背景。
- 激活态由主色、字重和 3dp 指示线共同表达。
- Tab 使用 44dp 触控高度，并保留 `Role.Tab` 和 selected 语义。
- 地点池与行程内容不得再添加与 Sheet 重复的页面级水平 padding。

## 6. 地图与 Sheet 协调

地图控件不能各自使用固定 bottom padding。壳层应提供统一的 Sheet 可见边界：

- 搜索入口、图例和地图控件基于同一边界避让。
- Sheet 在拖动过程中，相关浮层同步更新位置。
- 浮层不能被 HALF 或 EXPANDED Sheet 遮住。
- COLLAPSED 状态下地图仍为主要视觉区域。
- 地图加载或失败不得阻断地点池与行程的本地操作。

## 7. 地点池首批视觉规则

- 列表保持轻量行布局，不改造成厚重独立卡片。
- 行内图标、标题、元数据和添加操作使用稳定的横向约束。
- 标题可省略，操作区不可被长文字挤出屏幕。
- 去除工作台外层和地点池内容层重复的水平 padding。
- 保留“从地点池加入行程”的现有业务入口和状态语义。
- 地点池行右侧最终采用双按钮、单按钮还是菜单，不在本批自行决定。

## 8. 行程首批视觉规则

- 本批只保证工作台行程内容正确接入共享壳层和 Tab。
- 单日、全程、RouteLeg、编辑操作密度的细节设计放入后续批次。
- 保留全程只读、单日可编辑、三档 Sheet 和现有错误恢复语义。
- 不在壳层改造中重写 ViewModel、Repository 或异步 generation 逻辑。

## 9. 响应式范围

### 9.1 本阶段必须覆盖

- Mate 60 Pro 正常竖屏比例。
- 系统默认字体大小。
- 正常半屏地点池。
- 正常半屏行程。
- 展开行程。
- 搜索返回状态。
- 长旅行名的省略和操作区稳定性。
- 系统安全区、手势导航区域和常规窗口尺寸。

### 9.2 后续增强，不阻断本阶段

- 280dp 可用高度极端小窗。
- 横屏和分屏。
- 2×字体。
- 极端长文本和异常系统缩放。

本阶段不得主动破坏这些场景，但不为它们增加专门布局分支或验收门禁。

## 10. 待讨论项

以下项目保留当前行为或采用最小视觉调整，单独登记，不阻断壳层实施：

| ID | 项目 | 当前处理 |
|---|---|---|
| UI-TODO-01 | Profile 入口没有目标页面 | 保留入口和当前回调，不新增产品范围 |
| UI-TODO-02 | 地点池行右侧双按钮、单按钮或菜单 | 保留现有操作语义，只修复明显布局问题 |
| UI-TODO-03 | 设计稿中的地点数、规划进度等模型缺失数据 | 不伪造数据，不增加占位业务值 |
| UI-TODO-04 | 空态插画是否逐路径复刻 | 保留现有近似表现，后续统一决定资源精度 |
| UI-TODO-05 | 行程卡片操作密度和 RouteLeg 最终细节 | 放入行程内容批次讨论 |

## 11. 实施批次

### W1：工作台视觉基础

- 收敛工作台使用的颜色、字体、尺寸、圆角和 elevation 语义。
- 清理搜索和地图控件的局部品牌色与占位字符图标。
- 保持已有主题架构，不重做全应用 Theme。

### W2：共享壳层

- 建立统一的地图与 Sheet 空间协调。
- 收敛顶部栏、搜索入口、地图控件、图例和三档 Sheet。
- 修复原始 px 手势阈值和无边界拖动。

### W3：地点池接入

- 清除重复水平 padding。
- 统一列表行节奏、长文本约束和操作区。
- 保留当前选择、详情和加入行程语义。

### W4：行程接入

- 将单日与全程内容稳定接入新壳层。
- 只修复壳层引起的宽度、遮挡和可达性问题。
- 行程项和 RouteLeg 的深度视觉改造另行规划。

### W5：正常真机验收与回归

- 完成正常竖屏重点状态的设备抽查。
- 执行聚焦测试、静态门禁和代表性生产旅程。
- 记录非阻断视觉差异和待讨论项。

## 12. 测试与验收

### 12.1 自动化

- 工作台壳层 focused Compose tests。
- 三档 Sheet 高度、锚点和拖动边界测试。
- 长旅行名与操作区约束测试。
- 真实 NavHost：进入工作台 → 搜索 → 返回 → 切换地点池/行程。
- 地图失败时，本地地点池和行程仍可操作。
- 现有 47 个 typed executable 场景继续作为行为回归护栏。

视觉改动中的可测试行为遵循 RED → GREEN。纯颜色、阴影等无法通过行为测试表达的项目，通过组件预览和真机抽查验证。

### 12.2 真机抽查

使用 Mate 60 Pro 正常竖屏和系统默认字体，检查：

1. 半屏地点池。
2. 半屏行程。
3. 展开行程。
4. 搜索返回状态。
5. 长旅行名。
6. 地图失败降级状态。

每个状态检查地图占比、遮挡、裁切、关键操作可达性和状态一致性。无需逐屏截图或像素比较。

### 12.3 阻断条件

阻断：

- 功能或状态错误。
- 数据不一致。
- 崩溃。
- 流程不可达。
- 严重裁切或遮挡。
- 关键操作不可点击。
- 基础可访问性语义丢失。

不阻断：

- 小范围间距差异。
- 字体渲染差异。
- 细小圆角、阴影或颜色偏差。
- 系统状态栏和地图底图差异。
- 已登记的产品/设计待讨论项。

## 13. 完成定义

工作台 UI 收敛阶段完成需同时满足：

- 工作台共享壳层采用本设计的组件边界。
- 地图、顶部栏、搜索、地图控件和 Sheet 不互相遮挡。
- 三档 Sheet 与 Tab 行为保持稳定。
- 地点池和行程可完成原有关键流程。
- 聚焦自动化、构建门禁和代表性生产旅程通过。
- Mate 60 Pro 正常竖屏抽查无阻断问题。
- 所有未解决冲突均进入结构化待讨论清单。
