## Global Constraints

- 全局城市识别、创建交接、已有旅行导入、直接选图、重试和恢复均适用；不新增页面或设置开关。
- 最终地点上限100、图片最多处理20张、行程最多30天保持；3.4.0/build27/schema13不变。
- 链接超过20图不阻断文字：最多尝试20张安全且不同的图片，真实记录其他图未处理，不宣称完整覆盖；手选图仍遵守既有20张和字节限制。

interface AssistantLinkLoader {
