## Review Focus

- 助手不存在时搜索仍靠右；助手存在时不能把两个入口挤到左边。
- 32dp是视觉高度，点击目标至少48dp；扩展点击区不能挡住面板或互相重叠。
- 窄屏/大字体不截断「助手」，标题和摘要数字可读；不改变用户全局字号。
- 切换旅行日或数据迟到时摘要不能显示前一天站数；全程使用全程投影。
- 搜索结果、弹层和展开面板不露出可误触的助手；返回后普通搜索与助手仍可用。
