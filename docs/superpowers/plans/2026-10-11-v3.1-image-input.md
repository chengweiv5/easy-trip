## Global Constraints

- 每批最多6张；JPG、PNG、WebP静态图。
- 单张不超过10MB，总计不超过30MB；文字最多2000字。
- 解析仍最多20个地点；超过时保留完整素材，要求用户主动分批，不擅自只处理前20项。
- 图片、文字、图文混合均不弹发送确认；首次使用、后续发送或更换模型/端点均一致，不增加“始终允许”开关或一次性授权页。
- 先选图、预览、移除和补充文字，再点击「全部标记到地图」直接开始处理。选图不触发发送。
- 不包含拍照、系统分享接收、网页抓取、应用内裁剪/涂抹、视频或长期图片库。
- 原图不永久保存到地点池；原图、Base64、API Key不写入日志或普通备份。
- 截图文字只是输入资料，其中“忽略规则”“自动收藏”等内容不获得执行权限。坐标来自地图POI查询，不来自模型臆测。
- 沿用湖水绿主题、地图入口和标题；正文统一左右16dp。
- 上传/提交48dp，移除命中区44dp；来源条视觉高32dp、点击区至少44dp。
- 不改 schema11，不自动收藏、不自动排行程；地图授权及收藏/清空/离开确认不取消。
- 当前功能分支开发；本轮不安装用户手机、不推送、不创建 Release 或标签。
- 不改 `.pen`。需要改稿必须用 Pencil MCP 精确绝对路径只读核验后操作；不可用或失败立即停止受影响的设计工作。

### 明确工程取值

- 10MB/30MB 按 `10 * 1024 * 1024` / `30 * 1024 * 1024` 字节执行，UI 显示“10 MB / 30 MB”；单批数量和真实流大小均由应用再次校验，不依赖选择器承诺。
- 原图仅存在 `noBackupFilesDir/assistant-input/<session-id>/` 的会话临时目录；不申请整库权限，不持久化相册 URI 授权，不上传到第三方图床。
- 每张准备后的 JPEG：最长边4096、最多8,388,608像素、最多4 MiB；质量依次90/85/80/75/70，不为塞进预算继续无提示缩小。仍超限则报告该图准备失败并保留原图；不裁剪。透明图合成白底，EXIF方向/镜像烘焙到像素，新文件不复制元数据。
- 对头部声明的尺寸先做溢出安全检查；边长超过50,000或像素超过1,000,000,000则拒绝安全解码。JPG/PNG/WebP按实际内容识别；APNG/动画WebP拒绝，不把首帧冒充静态图。
- 网络逐图串行，文字非空时最多额外一次文字提取；每请求45秒、连接15秒，POI并发2/单项15秒。纯文字整批90秒，含图片整批540秒；不自动重试。每请求含Base64的JSON上限6 MiB，响应上限256 KiB。停止按钮全程可用。
- 混合输入中的文字会作为每张图的上下文，但图片请求只提取该图内的明确地点；文字来源只通过单独文字解析收录。最多7次模型请求，不对每个地点再调用模型。UI常驻说明按文字/图片分别处理并可能产生多次费用。
- 整批初次提取完成（含部分失败）后检查总地点数，再开始POI；超限时不查询任何截断子集。定向重试若导致超限，保留原有成功地图结果，不添加新结果，要求重新分批。
- 图片来源摘录标明“模型提取，需对照原图”，不冒充应用已独立验证的OCR。模型给出的残缺/不确定名称进入待核对，不自动通过；名称/城市依旧只能用地图结果确认。
- 图片能力是当前准确配置的检查结果，不按模型名字猜测。UNKNOWN 可主动检查或点击直接发送；明确 UNSUPPORTED 本地拦截。文字测试成功不能设置为 AVAILABLE。
- v3.1 实施时版本改为 `versionName = "3.1.0"`、`versionCode = 22`，schema仍11。最终打包前再次核对主线版本，若22已被其他已发布包占用，递增至当时已核实的下一整数并记录，不降级覆盖。
