# Easy Trip 一期实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个仅本地存储、以高德地图为核心的 Android 旅行规划 App，让用户收藏 POI、手动编排多日行程，并查看真实路线。

**Architecture:** 使用单体 Android App，按 `trip`、`place`、`itinerary`、`route`、`workspace` 责任分包。Room 是唯一持久化事实源；所有编排操作先在事务中更新行程项和邻接路段，再由路线协调器异步调用高德适配层，Compose 页面只消费 `StateFlow` 状态。

**Tech Stack:** Kotlin、Jetpack Compose、Navigation Compose、Room、ViewModel、StateFlow、Coroutines、高德地图 Android SDK、高德搜索与路线规划 SDK、JUnit、kotlinx-coroutines-test、Room instrumentation tests、Compose UI tests

**Spec:** `docs/superpowers/specs/2026-08-21-easy-trip-v1-design.md`

## Global Constraints

- 一期仅开发 Android，不增加跨平台抽象或 Gradle 多模块。
- 一期不提供 AI、登录、云同步、协作、分享、导出、自定义地图落点、预订、实时导航、费用管理、自动排序或后台定位。
- 所有业务数据保存在 Room；成功路线可离线查看。
- 同一高德 POI 在同一旅行中只收藏一次，但可生成任意多个行程项。
- 不同旅行日之间不生成路线；路线只连接同一天相邻的行程项。
- 自驾游推荐驾车；非自驾游按 `≤1 km 步行`、`>1 km 打车` 推荐。
- “打车”和“自驾”均调用高德驾车路线，但保留不同产品语义。
- 路线失败不得阻止保存或编辑行程，不得伪造距离、耗时和轨迹。
- 使用 Java 17、`minSdk 26`；`compileSdk` 和 `targetSdk` 使用 Android Studio 当前安装的最新稳定 SDK。
- 高德 API Key 只通过未跟踪的 `local.properties` 注入，禁止提交密钥。
- 每个功能任务遵循红—绿—重构；每次提交前运行该任务列出的完整验证命令。
- 计划中的提交步骤只有在用户明确授权实施阶段提交时执行；否则保留工作区变更并报告。
