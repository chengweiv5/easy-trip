# v2.0.0 花费一级入口与内联多笔费用 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现已确认的六类地点多笔费用、地点原位记账和跨旅行年月回顾，完整保留现有旅行能力与旧费用。

**Architecture:** 地点费用从行程项单金额演进为具有稳定 ID 的独立记录，外键归属于具体行程项而不是收藏地点；路段保留单金额。Room 以一致快照提供明细，纯 Kotlin 模型负责旅行日归属、分类和年月汇总；原地点编辑 ViewModel 持有整份草稿，Repository 在一个事务内提交地点与费用。Compose 复用现有导航、主题和表单组件，不照截图建立第二套平行实现。

**Tech Stack:** Kotlin 2.2.10、Room 2.7.2、Compose、StateFlow、JUnit4、现有 Android instrumentation 测试；不新增生产依赖。

**Spec:** `docs/superpowers/specs/2026-10-09-v2.0.0-expense-review-design.md`

**Pencil:** `design/easy-trip-v2.0.0.pen`，SHA256 `d31d42703006c980835111b7c60941918d4c44bbfe14f45def85af55598eae3e`。

**Implementation baseline:** 设计提交 `c3e43ce11cfb8fec9ec11dc68ca03d3302919dac` 已快进推送到 `origin/main` 并回读确认；实际实现 v1.8.3/build13、数据库版本8。原8项运行断言不自动关闭。

## Global Constraints

- 一个版本一份完整 Pencil 快照，设计更改仅使用当前工作树的 Pencil MCP。
- 费用类别只包括住宿、交通、景点、吃饭、购物、其它；旧数据的“待分类”是缺失类别，不是第七类。
- 日期为 `trip.startDate + day.index`，index从0开始；无日期计入全部、单列未确定日期，不计入确定年月。
- 不新增预付、实付、付款日期、支付状态、独立于旅行来源的记账。
- 0元是有效记录；空白不生成记录；金额以Long整数分保存，禁止负数、舍入和溢出。
- 同地点、同类别可多笔；再次安排收藏地点不复制原行程项的费用。
- 地点时间、停留、备注和费用增删改原子提交；失败全留稿，取消整份放弃。
- 路段仍是现有单金额、固定交通分类，归路线所属旅行日。
- 未完成实现前不把APK版本伪装成已完成的v2.0.0；最终验收批再升级为2.0.0/build14。
- 每批功能分支提交；未经本批验证不推送代码。用户已授权此次设计提交推送和开始开发，发布APK/安装到个人手机另行确认。
- 默认保持当前功能分支和6934工作树，不开新工作树、不改主仓库。

## Review Focus

1. **旧费用/零元迁移**：一条非空旧金额恰好迁移一次，0元保留，NULL不生成，取消或升级失败不改用户账目（Task 2）。
2. **同地点同类别多笔**：身份按费用ID而非类别；新增/修改/移除不误操作另一笔，脏草稿统一提交或放弃（Task 1、3）。
3. **跨年和未定日期**：历史补录不进入录入当月；改日期或移日只重新归属，不改变金额/ID，不重复计旅行（Task 1、4、5）。
4. **并发/来源失效/失败**：已删除来源、外部费用变更、迟到异步结果禁止覆盖新状态；事务失败不产生部分保存（Task 2、3、5）。
5. **溢出与大字体**：聚合溢出显示错误而非伪0；键盘/窄屏/大字体下保存、取消与范围选择仍可达（Task 1、3、4、6）。

enum class ExpenseSourceKind { PLACE, ROUTE }
data class ExpenseKey(val kind: ExpenseSourceKind, val id: String)
data class ExpenseRecord(
    val key: ExpenseKey, val tripId: String, val dayId: String,
    val sourceId: String, val sourceName: String, val date: LocalDate?,
