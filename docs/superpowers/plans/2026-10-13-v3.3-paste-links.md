# v3.3 粘贴链接实施计划

执行：用户要求规格完成后直接开发；当前会话原生顺序实施，不再次设置审批等待。规格见同目录上级 specs 的 `2026-10-13-v3.3-paste-links-design.md`。

## 1. 基线与设计

- 功能分支 `codex/v3.3-paste-links` rebase `origin/main 6a1497b`；保留抽屉地图视角修复。
- 将 v3.2 累积源复制为 v3.3，仅用 Pencil 修改输入、进度和上限文字，不改布局。原生保存重开，检查 320dp 文字。

## 2. 数量限制纵切

先写 `AssistantImagePolicyTest`：第 20 张接受、第 21 张拒绝；原字节溢出保护不变。将全部六张硬编码统一为 `AssistantImagePolicy.MAX_IMAGES = 20`；系统选图器、添加按钮、存储、控制器共用。整批超时使用素材数预算：

```kotlin
fun batchTimeoutMillis(imageCount: Int): Long =
    (180_000L + imageCount.coerceIn(0, MAX_IMAGES) * 75_000L).coerceAtMost(1_800_000L)
```

每个切片先运行定向 JVM 测试，红后绿，不一次堆积全部测试。

## 3. 输入和文档获取纵切

新增 `AssistantLinkInput`、`AssistantLinkPolicy`、`AssistantLinkDocument`、`AssistantLinkReader`。入口公开函数解析文本或返回 null；不支持／多链接抛安全用户消息，不泄露 URL 参数。文档包含平台、标题、正文和有序图片 URL。用纯 JVM 测试输入和校验策略；Android 页面读取器以只读 DOM 脚本抓取，配离线 HTML/JSON 结构样本和 opt-in 真实链接测试。

## 4. 图片导入纵切

扩展图片存储的受控远程素材接入，沿用 MIME／像素／字节校验。使用白名单 HTTPS 下载器，限制重定向、累计字节与数量。失败／取消仅清理新 ID。逐图读取、prepare、销毁临时位图。仪器测试在独立缓存目录验证 20 图和回滚。

## 5. 助手接线纵切

在 submit 的现有文字／图片分支前加链接准备阶段，输入解析成功才联网。读取完成的代次仍有效才更新草稿，原分享文本保留，正文供现有解析器处理。抓取阶段独立进度；busy/cancel/clear/save-success 均清理链接状态。复用现有 `AssistantInputProcessor` 逐项重试，保持城市、POI、选择与事务不变。

新增控制器测试：失败不送模型、取消晚到、成功只抓一次、部分模型失败不重复抓取、收藏新一轮不携带旧来源。应用容器注入 reader/downloader，不让 UI 依赖网络实现。

## 6. 收尾

```text
./gradlew testDebugUnitTest testReleaseUnitTest lintDebug lintRelease assembleDebug assembleDebugAndroidTest assembleRelease --max-workers=2 --console=plain
```

隔离模拟器跑相关助手 UI、320dp/双倍字体与两条真实分享读取；不安装用户手机。不扩大修复历史无关失败，独立审查后修复本次缺陷。记录验证证据、未验范围、文件级回滚；punk-12 通知并回读，状态文件最后更新。不自动提交产品、推送或发布。

## Review Focus

- URL 误识别造成任意站点／内网访问：策略测试和重定向下载测试。
- 验证页、推荐图误当正文：文档解析完整性及原帖轮播测试。
- 抓取取消后图片遗留或晚到覆盖新批次：存储回滚与控制器代次测试。
- 20 图仍被 UI/存储六张硬编码或 540 秒预算截断：边界与超时预算测试。
- 新批次清理删除用户刚加的新图：既有自动新一轮回归及链接文件 ID 清理测试。
