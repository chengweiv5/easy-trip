# App 设置与版本更新 · 本地开发验证

日期：2026-10-01。分支：`codex/app-settings-update`。

## 实现
- 首页右上角齿轮进入 App 设置，空旅行列表也可进入。
- 主题配色、地图授权迁移到 App 设置；沿用已有全局存储，不重置数据。
- 工作台更多菜单只保留旅行设置、分享行程长图和返回旅行列表；地图未授权时仍有就地授权入口。
- 当前版本与构建号取 BuildConfig；不依赖网络。
- 正式版本手动检查、更新说明、下载进度/取消/重试、系统安装许可与安装确认交接。
- 正式发布比较不降级；非法元数据不当作最新版本。
- 下载固定 GitHub 官方仓库发布 APK；HTTPS、受限重定向、响应/文件大小限制、完整 SHA-256 验证。
- 安装前再次验证摘要、包名、版本、递增 versionCode、相同签名；FileProvider 只共享更新缓存，只授予读权限。
- 取消使用请求代际隔离，迟到完成不覆盖新状态，临时下载清理。
