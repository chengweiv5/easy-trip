相对 v3.3.0：

1. 首页「助手创建」支持粘贴携程社区／小红书攻略，先识别目的地城市与旅行信息；日期可选，多城市不硬套一个城市。
2. 一次「创建并导入攻略」确认后创建空旅行、自动进入旅行内助手并只交接一次原攻略和城市上下文；复用地点识别、地图匹配和手动收藏，支持失败恢复，不自动安排每日路线。
3. 每批最多100地点、20图，旅行最多30天。文字独立处理，图片全链路可选；单图失败可跳过，只有图片且无有效结果仍如实失败。
4. 自动提取只关注独立游览目的地，排除餐饮、推荐住宿、停车场、景区内部设施与底图背景名称；按作者证据整理实体／别名。手动添加不受自动筛选范围限制。
5. 部分失败不阻塞成功项；一次收藏成功结束整批，只有写入失败保留幂等重试，防旧草稿复活。新候选默认「景点」，不回填已有收藏、旧草稿显式类型或用户手动类型。
6. 双平台链接加固、协议兼容与单项错误隔离、正圆地图标记及助手半展开地图定位。

不包含大众点评、系统分享扩展、语音输入、自动每日路线。上述筛选是实现目标与规则，不是任意攻略识别质量的保证。
