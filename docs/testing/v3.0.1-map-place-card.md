## 2. 地址问题的原因及修复

原地图点击路径调用 `Poi.toMapPoiUi(address = "")`，默认地址为空；旧弹窗直接将空值显示为“地址暂不可用”，未按 POI ID 查询详情。因此底图地点没有地址，并不等于高德详情服务没有地址。

相关实现：

- `/Users/bytedance/.codex/worktrees/2df7/easy-trip/app/src/main/java/com/yangchengwei/easytrip/place/amap/AmapPlaceDataSource.kt`：增加 `details(poiId)`，使用真实 `searchPOIIdAsyn`，复用 SDK 回调桥、隐私校验与地点解析。
- `/Users/bytedance/.codex/worktrees/2df7/easy-trip/app/src/main/java/com/yangchengwei/easytrip/workspace/MapPlaceDetailsController.kt`：已有地址直接显示；空地址查询时显示加载；8 秒超时/查询失败可重试；明确区分无地址和失败；关闭/切换会取消查询，旧结果不能污染新卡片；验证返回 POI 身份并保留点击名称与坐标。
- `/Users/bytedance/.codex/worktrees/2df7/easy-trip/app/src/main/java/com/yangchengwei/easytrip/workspace/MapPlaceDialog.kt`：收藏回调使用补全地址。加载中禁止新增收藏，已有收藏仍可取消；失败或确实没有地址时允许继续收藏；没有稳定 POI ID 时禁用收藏。
- `/Users/bytedance/.codex/worktrees/2df7/easy-trip/app/src/main/java/com/yangchengwei/easytrip/workspace/TripWorkspaceScreen.kt`：统一底图地点/日程标记的轻量卡片；已有地点池详情抽屉保留。

- 标题区关闭点击区为 48×48dp，长标题时顶部对齐，不随多行文字落到中部。

- 保留 loading、失败重试、未提供地址、无编号、收藏中、收藏失败等状态。

### 失败记录与修正

- 关闭按钮初版在 320dp 双倍字号下随长标题垂直居中，新增顶部对齐断言先失败，修改后通过。
- 通栏按钮在紧凑版断言下先失败（`The action must not fill the content width`），修改后通过；证据 `device/compact-red.txt`。
- 旧“固定 44/48dp”测试误用于双倍系统字号，曾因自然增高到约 61dp 失败。改为普通字号精确尺寸、大字号最小尺寸及增高断言，没有压缩产品文字来满足测试。
- 调整测试时 DpRect 的宽高访问曾编译失败，已改成边界差值，最终两套设备专项重新通过。
- 早期 Java 25 环境不兼容、共享 Gradle socket 诊断等保留在历史日志；最终使用 JDK21、`--max-workers=2` 构建成功，未重启共享 daemon。
