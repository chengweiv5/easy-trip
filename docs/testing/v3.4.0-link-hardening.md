## 实现

1. 仅拆开已知小红书后缀与紧贴URL，不盲删Unicode或签名参数。
2. 小红书提取与下载安全校验同步支持两种已实测图片路径，主机仍限定可信图片CDN。
3. `AssistantLinkDom`集中两平台公开DOM适配。携程绑定原文章及其轮播，小红书绑定原笔记轮播；排除推荐、评论、头像及广告区域。
4. 总数仅从原帖媒体区的计数、分页或明确元数据获取。无可信总数不猜单图；冲突、懒加载未齐保持未完成；已知超过20图和视频立即拒绝。
5. 同一原图的签名／尺寸渲染变体去重，但所有URL仍逐一安全验证，不以去重掩盖不可信来源。
6. 空／缺失／空白`src`作为待加载，不把页面URL误当图片；空白`src`配合`data-src`可以读取。
7. 连续三次完整文档才成功，中间不完整或无效JSON重置稳定计数；外层取消不转换为内部超时。
8. 仍是45秒总读取预算。到期区分无正文、无法确认总数、图片未齐、结构不支持与普通超时；**不宣称未知结构快速失败**。已有错误位置显示原因，原输入／已建旅行保留。
9. 默认诊断仅记录平台、适配版本、阶段、计数、原因与主机，不记录正文、完整URL、token或密钥。
