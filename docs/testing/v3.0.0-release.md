### 本版功能

文字多地点输入 → 匹配真实地图 POI → 全部标记候选 → 用户逐项或勾选确认收藏。未确认不写入地点池；收藏不会自动加入行程。同名、失败、未匹配候选独立处理。

地图左下实心「助手」与右下搜索同排等高；助手正文左右16dp。配置统一在App全局「助手设置」，原生Kotlin Runtime直连Provider，网关可选。保留v2.2.1两行每日标题和普通新收藏默认景点。

**不包含**图片输入、第三方平台抓取、自动决定景点或全App通用Agent操作；不混入v3.1开发内容。
