## 1. 明早从这里看

1. 打开任意旅行，在地图的普通「搜索地点」旁点击 **✦ 助手**。
2. 首次前往 **App 设置 → 助手设置 → 模型服务**，填写 HTTPS Base URL、模型名及自己的 Key，点击「测试连接并保存」。设置是全局的，不属于旅行设置；更换地址会清空编辑中的 Key，避免旧凭据发往新服务。
3. 输入城市和多个地点，例如“把杭州的灵隐寺、河坊街、雷峰塔标记出来”，确认发送范围后点 **全部标记到地图**。
4. 明确位置直接以 A/B/C 标记；同名、城市冲突、无结果、失败单独处理。点击项目聚焦对应位置，可返回「查看本批全部标记」。
5. 选好后点击 **核对并收藏所选 → 确认收藏**。全选、标记、选择候选都不写库。单项也必须经过核对确认；默认分类“其他”，可改为现有五分类。
6. 查看回执/地点池；未解决项继续保留，失败项可单独重试。收起保留当前草稿；清空或退出旅行要确认。草稿不保证进程恢复，但收藏和最近回执持久化并回读。

建议微调顺序：入口是否醒目 → 半屏列表与地图比例 → 歧义候选的核对成本 → 批量确认信息密度。320dp/2倍字验证按钮可滚动到达，但内容区域较紧，可以考虑下次提高默认面板高度。

## 2. 实现范围

- `assistant/DeepSeekPlaceParser.kt`：OkHttp直连、一次只读 `search_place_batch`；严格校验完整响应、唯一工具、items/overflow、query原文证据和城市来源。模型没有收藏、SQL、Shell或任意URL工具。
- `PlaceAssistantController`：StateFlow、每项稳定ID/generation、有界查询、取消与迟到结果隔离、城市核对、重复代表稳定、选择快照与确认门禁。
- `AssistantConfigStore`：Keystore AES/GCM + noBackupFilesDir + AtomicFile；Key不入Room/日志/APK；设置页FLAG_SECURE，默认掩码，测试成功才保存，失败保留旧配置。
- `PlaceAssistantPanel`/ViewModel/地图适配：复用同一个MapView和旅行工作区底部面板。临时字母标记与正式分类标记区分；助手不永久抢占普通搜索/行程地图相机。
- `RoomPlaceImport`：所选新地点、类别与回执单事务，已有POI保持旧内容，operationId/digest幂等；同ID不同内容拒绝。schema10→11仅增加回执表与索引，外键跟随旅行删除。
- 上限：输入2000字符、20地点、词100字符、城市50字符；真实POI最多2并发/每项15秒/整批90秒；模型45秒/4096tokens/响应256KiB，无自动重试和重定向。
- 版本为 **3.0.0/build20/schema11**。未加入截图/分享抓取、行程操作、费用操作、Agent撤销或长期任务存储。
