## 规则与改动

提示词是按处理阶段固定的源码模板，每次请求重新组装消息，不由模型临时生成System Prompt。具体城市、正文、名称和候选来源只作为当次User消息数据。容量等工程参数由代码填入，不是旅行内容。

用户指出最终语义去重的固定规则不应写入具体旅行样例。本轮移除其中具体景点／城市别名与食品示例，替换为通用实体判断：

> 仅以本次资料、城市和候选来源证据为依据；简称、全称、别名或带有／省略通用类别后缀的名称，只有证据确认同一实体时才合并。不能仅凭名称相似或去掉后缀判同。泛称仅在上下文唯一指向已有明确候选时合并，不补造名称。

食品／餐饮剔除、住宿保留、背景过滤、禁止包含关系强行合并、候选ID覆盖校验和最终20地点限制均未改。

其余生产提示词未发现同类具体旅行示例。设置页的“连接测试”及图片能力探针使用明确标为测试的地点素材，属于测试User输入／合成图，不是生产System规则；保留这些测试，历史报告及真实回归样例也不抹除。
