# v3.0.2 助手搜索城市修复

日期：2026-10-11。工作树：`f254/easy-trip`；分支：`codex/v3.0.2-assistant-city`；代码基线：`ed1bf0c`。用户明确将本次修复归入 **3.0.2/build23/schema11**。

## 问题与根因

用户真机截图中当前旅行为“徐州”，输入“云龙湖、云龙山”后，两项均提示“请补充搜索城市”。

原助手仅在打开时从地点池当前城市填入默认值，没有在提交时连接旅行名称的城市解析；地点池没有可用城市时，解析器收到空默认城市。结果页又隐藏初始输入区，只剩逐项修改。

## 修复范围

- 保留用户明确填写的默认城市；否则先读取地点池当前城市，再使用已有高德行政区划查询确认旅行名称中的**唯一城市**。
- 不把任意旅行名称直接当城市，不用当前位置，不为多城市或歧义名称猜一个城市。空旅行地图原有“首个城市定位”行为不变。
- 城市解析在原有本次发送授权之后、模型调用之前执行，12 秒上限；失败或超时仍保留正常的缺城市澄清路径。取消、城市修改或权限失效时不接受旧结果。
- 结果页增加“补充本批搜索城市”：统一填写一次，只重查城市为空的待处理项，不重新调用模型，不覆盖其他明确城市、结果或选择，不自动收藏。
- 初始城市框解释留空规则。schema11 不变，无迁移、无数据清理。
