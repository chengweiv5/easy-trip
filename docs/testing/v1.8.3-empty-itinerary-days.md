收藏地点与旅行日程是两个独立状态。设置 3 天只建立旅行日，不自动分配收藏地点。
原先 `TripWorkspaceContent` 在 `isItineraryAllEmpty && !calendarMode` 时显示整页空态，
绕开了 `WorkspaceItineraryContent`，连同旅行日侧栏和当天加号一起隐藏。
本次移除这个显示层覆盖分支，复用已有全程、单日、日历和 `ForDay` 添加流程。

半屏验收还复现了当天空态的 96dp 插图挤掉提示文字，因此仅将当天空态调整为
42dp 插图、紧凑标题及说明；不修改通用 `EmptyState` 或其他页面样式。
未修改数据库、迁移、收藏或分配算法，没有读取或修改手机中的“青州”数据。

## 行为验收

| 场景 | 结果 |
| --- | --- |
| 3 天全部为空，已有收藏 | 保留全程及第 1/2/3 天导航；每一天均能点加号 |
| 从第 2 天添加 | 弹出目标为第 2 天的地点选择器；确认后回到第 2 天 |
| 第 2 天添加一个地点 | 第 2 天显示该地点；第 1/3 天仍为空；收藏集合不变 |
| 取消添加 | 返回原选择日，所有日程保持不变 |
| 无日期、无收藏、1 天 | 第 1 天与加号可见；空选择器可关闭、确认按钮禁用，不造数据 |
| 半屏空日 | 标题和说明的完整边界位于时间线视口内，不仅是“部分可见” |
| 全程概览 | 显示所有空旅行日和 `全程 · 3 天 · 0 站` |

测试使用真实公开 Compose 组合根、生产 `AppNavigation`、内存 Room 仓库和 fake map。
没有模拟高德瓦片或把示意地图称为真实地图验收。
