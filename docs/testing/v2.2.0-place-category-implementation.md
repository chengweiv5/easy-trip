1. 仅有景点、住宿、餐饮、交通、其他五类；旧收藏、新收藏及未知存储值读取时都回退其他，无独立“未分类”。稳定键为 `attraction/lodging/food/transport/other`。

3. 编辑收藏分为地点分类、收藏备注、标签三区。分类上三下二单选，选中有浅色背景、描边、勾号；标签多选、自定义及原有校验保留。列表、详情、编辑共用分类样式。
