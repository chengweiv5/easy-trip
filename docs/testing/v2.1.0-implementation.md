- 花费年度、历年、月度、分类、旅行全程／单日、未定日期和费用明细采用统一白色模块面、标题图标、细分隔与 24dp 模块间距；列表行不重复套卡。

- 原父级年份、分类／旅行范围与滚动位置保留。选择器使用勾选和 selected 语义；大字号减少月份列数。
- 空、加载、失败保留年月导航；选择器未读取数据时显示“统计待加载”，不冒充无记录。
- 无记录与真实零元分别保留“尚无记录”和 `¥0.00`／真实笔数。未定日期在全部范围注明已包含在总额中。
- 独立花费编辑分为来源／金额类别；分类勾选、删除确认、日期影响提示沿用已有写入与事务路径。
