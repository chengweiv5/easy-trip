# v2.0.0 发布验证

2026-10-09；本页记录正式包、README 介绍和公开发布的验证边界。当前阶段：发布前检查完成，公开发布结果将在回读后补充。

## 本版变化

- 「旅行／花费」一级入口，支持历年、年度、月度、类别及旅行明细。
- 地点可记多笔费用，类别为住宿、交通、景点、吃饭、购物、其它；同类可重复。
- 第一笔在编辑地点页直接填写，时间、停留、备注与费用统一保存／取消。
- 按旅行日归属年月；未定日期单列，跨年月或未定日期的调整先确认影响，不新增预付／支付状态。
- Room schema8 → 9：原地点金额迁移为独立的待分类记录，保留零元、不重复统计；路段仍为单笔交通。
- 累积保留 v1.8.3 的可选日期、空旅行日、搜索地图、主题、日历和行程长图。
