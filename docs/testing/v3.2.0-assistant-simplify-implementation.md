## 已实现

1. 删除“核对并收藏”、独立收藏确认页和回执中转。结果一直留在地图工作区，勾选后直接点击“收藏（N）”。
2. 每行复选框在最左侧，与底部全选同列；热区 48×48dp，框 20dp。全选支持未选、半选、全选及取消全选。
3. 底栏独立于滚动内容，零选禁用收藏。重复、已收藏、失败、缺城市等项不参与全选；晚完成项不自动选中。
4. 点击地图字母、名称或图钉只聚焦，不改变选择、不写入。地图浮卡显示名称地址，分类及更换入口展开当前面板详情。
5. 分类、候选、来源及异常单项名称／城市原位展开；只重查修正项。收起保留草稿，清空与离开保护保留。
6. 点击收藏创建不可变快照；同步锁定保存状态、防双击。同内容失败重试复用 operationId；选择／分类／候选内容变化则使用新操作。Room 仍负责原子性、幂等、旅行存在和坐标校验。
7. 执行前再次检查旅行有效、地图就绪、地图授权及运行代次。成功标记已收藏并保留本批其他结果；失败就地提示并保留选择。保存期间禁用选择、分类、候选、清空、来源重试及停止按钮。
8. 助手标题使用设置与收起图标，移除重复入口；大字模式提高半屏面板的最小高度至 360dp，受 expanded 上界约束。非助手工作区默认锚点不变。
