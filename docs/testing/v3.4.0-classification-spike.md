## 隔离试验方法

- 使用专用配置中的真实 DeepSeek `deepseek-flash`，三篇攻略各三轮，候选顺序分别为原顺序、倒序、固定随机打乱；9次HTTP200，无HTTP自动重试。
- 输入是上一轮保存的公开正文和明确标为“未核验”的模型图片描述；徐州另补8项既有诊断整理的具名回归上下文，明确不是新提取结果。
- 没有重新读取网页或图片，没有原图输入；不能当作 Easy Trip 全流程或真实图片识别验收。
- 脚本只在仓库外证据目录运行，未集成产品代码。

模型输出 `id`、`purpose`、`granularity`、`independent_visit`、`parent_id`、`evidence_quote`。隔离脚本检查全部候选覆盖、无新增／重复ID和父ID有效性，再按以下顺序执行：

1. 引文不是提供文本的连续片段，或分类为 `UNKNOWN`：`PENDING`，不进入地图查询。
2. 用途不是 `SIGHTSEEING`，或层级不是 `DESTINATION`：`DROP`。有效住宿分类 `LODGING` 没有豁免。
3. 其余条件满足但 `independent_visit=false`：视为冲突，`PENDING`。
4. 游览目的地、独立到访且引文校验有效：`KEEP`。

这里的 `PENDING` 是试验判定，不是已经新增的 App 界面或恢复状态。引文能匹配输入，也不能证明旧模型描述符合原图。
