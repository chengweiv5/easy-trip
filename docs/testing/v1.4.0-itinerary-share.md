# v1.4.0 行程长图分享验证

用户已确认 R2 设计。本次实现每日地图、全程／单日、备注开关、长图放大、相册保存与 Android 系统分享。

## 使用

旅行工作台 → 更多 → 分享行程长图。默认全程且包含备注；「选一天」确认日期后切换范围。所有输出使用与预览相同的 PNG（1080px 宽）。系统分享只打开目标选择面板，发送由用户完成。

- 地点与交通从只读快照导出，保留重复到访；只使用同日当前相邻节点的路线。
- 成功且有效的路线画实线，其他已定位相邻点画虚线，注明到访顺序。每天单独取景并使用该日颜色；重叠编号合并，清单不合并。
- 无授权、缺坐标或截图超时仍保留清单并说明原因，可重新生成。有效快照缓存支持离线重用；临时缓存保存 7 天。
- 先测量完整内容再分配图片；最高 30000px，像素预算不超过 2400 万或最大堆的 1/16（以像素数计，ARGB 位图约占堆的 1/4）。超预算引导单日，单日仍超预算可关闭备注或调整内容，不静默截断。
- FileProvider 只暴露导出缓存子目录，分享使用只读 content URI。Android 10+ 用 MediaStore pending 写入，8–9 仅保存时申请存储权限。

## 已执行验证

结果：812 项单元测试通过，12 项相关仪器测试通过，lint 0 错误（48 条警告），debug APK 构建成功。

环境：JDK 21、Android API 36，独立只读 AVD 副本 emulator-5590。未安装或操作连接真机。

- 单元测试覆盖保留重复到访、逐日编号、空日、跨日／过期路线、有效实线、损坏路线回退、交通覆盖时长和缺坐标。
- 仪器测试实际生成 PNG，检查尺寸、地图像素、长备注增长、隐藏备注、单日高度、页脚与超预算拒绝。
- 读取 FileProvider URI 与 MediaStore 相册结果，字节与预览 PNG 一致，MIME 和授权正确；测试创建的相册记录完成后清理。
- UI 覆盖默认选项、单日选择、备注、连续滚动、放大返回、快速切换期间禁用旧输出、空行程、读取失败重试。
- 高德 SDK 真实截图通过，保留署名、地图编号与每日颜色；密集编号合并、取消释放、无授权／撤回授权回退通过。首次冷启动曾超时，回退不阻断清单；后续真实截图通过。
- Android 原生分享面板已检查截图与前台包，取消后返回原预览并恢复按钮。首次设备开机遗留 System UI 弹窗已按日志确认并清除，之后通过。
- 更多菜单四项可见，分享前先关闭菜单；菜单边界按新高度计算。真实 Room 数据的旅行列表 → 工作台 → 分享 → 返回导航链路通过。

## 限制与回滚

Android 8–9 的运行时存储授权、各品牌相册、真实聊天客户端压缩与接收效果尚未真机验证。地图首次加载依赖高德可用性；最长每个非空日等待 12 秒，失败显示回退说明。不含账号、公开链接或多人编辑，不发布正式 Release。

无数据库迁移。回滚应用改动可在功能分支对本次功能提交执行 `git revert <commit>`，检查后再按项目快进规则交付；不回退用户已保存到相册的图片。重要原文件备份位于本地 `implementation-before/`。
