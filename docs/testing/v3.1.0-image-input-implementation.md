## 已实现

### 输入与确认

- 系统多图片选择器，最多6图；纯文字、纯图、图文均点击「全部标记到地图」直接处理。首次发送、后续发送不经过 App 发送确认，也没有新增“始终允许”开关。
- 选图、缩略图、预览和移除不发送模型请求；选择器回调与草稿修订绑定，清空/配置变化后的迟到回调不能回填。
- 附件横滚、图号、预览缩放/平移、重置缩放、移除；图片绘制区域裁剪，避免放大后覆盖关闭操作。
- 收藏、清空、离开确认仍保留。模型解析、地图标记、勾选和进入核对均不直接写收藏；最终确认沿用原子、幂等导入。

### 文件与协议

- 实际内容校验 JPG/PNG/WebP；拒绝动画 PNG/WebP。单图10 MiB、整批30 MiB，文字2000字符，整批20地点。
- 原图只存 `noBackupFilesDir/assistant-input/<session UUID>/`；有界读取，按会话删除，启动时只清理本模块旧进程会话目录。
- 准备 JPEG 时处理 EXIF 方向/镜像、白底、元数据剥离；最长边4096、最多8,388,608像素、最多4 MiB。缩略图256px；预览也是预算内缩放图，不承诺原图全分辨率无限放大。
- HTTPS、禁止重定向和自动重试、45秒请求/15秒连接超时；请求最多6 MiB、响应最多256 KiB。不把服务原始错误正文、Key 或 Base64 写入错误提示/日志。
- 只接受一个 `search_place_batch` 工具调用和严格参数；拒绝写工具、坐标字段、额外属性、无依据名称和类型错误。图片来源标识由本地绑定。地点坐标来自真实 POI 查询边界，不使用模型坐标。
- 超过20项或模型主动报超限均阻止整批新增查询；即使模型错误地写 `overflow=false`，实际21项也按超限处理，不当作普通图片失败后继续部分查询。

### 批次、取消与设置

- 文字一次、图片按顺序逐张提取；分来源记录结果/错误，保留成功来源与已选择地点。重试只重新请求失败/未完成来源。
- 明确 `UNSUPPORTED_IMAGE` 后，后续图片不再准备或发送；区分尚未发送、可能已发送、已收到服务响应。
- 停止保留素材和已经提取的地点，迟到结果不能覆盖新批次。尚未查询的结果可继续；跨城市、缺城市、模型不确定项仍需核对，不因停止绕过检查。
- 相同 POI 合并可收藏代表并保留所有来源；不自动收藏或排程。
- 图片能力用内置合成中文地点图片独立检查，结果绑定保存后的 URL/model/key。旧检查不能写入新配置，文字通过不表示图片可用。
- 设置检查期间不能重复发起或编辑；返回会取消检查并离开。取消仍不保证已发内容可撤回。
