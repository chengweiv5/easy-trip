## 实现

1. 地点池只保留左侧彩色分类按钮，不再叠加名称上方的分类徽标；名称、地址、安排状态、收藏备注和标签保留。
2. 单日、全程清单和日历名称前显示同一套分类资源；日期颜色和序号保留。长图模型携带分类，渲染直接复用 App drawable 和分类色，不另画近似图标。已经导出的图片不自动修改，重新生成才会更新。
3. 五分类为景点、住宿、餐饮、交通、其他；“其他”使用中性灰空心地点图钉，不新增“未分类”。
4. 图标打开五分类对话框，当前分类有选中标记，选择后立即保存并在成功后关闭；保存中禁止重复选择和关闭；失败保留当前分类与重试提示。大字体内容可滚动。
5. `SavedPlaceRepository.updateCategory` / DAO 单列 UPDATE 只修改 `saved_places.category`，不使用整个地点对象回写。已验证收藏备注、标签、重复安排的行程备注和历史费用保持不变；同一收藏的多个行程引用读取新分类。
6. 工作台统一持有快捷对话框，地点池嵌入模式不重复弹窗。日历触摸子图标不打开卡片、不开始拖动；键盘处理只在卡片自身聚焦时生效，子分类按钮的 Enter/Space 不被父卡片截获。
