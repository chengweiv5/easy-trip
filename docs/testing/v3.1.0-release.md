## 本版功能

- 最多6图，纯文字/纯图/图文混合输入；缩略图、预览与移除不触发模型上传。点击「全部标记到地图」直接处理，无首次/后续发送确认；没有新增“始终允许”开关。
- 图片按来源记录进度、失败和重试；停止后保留素材与已提取地点。所配置服务/模型的图片能力独立检查，不以文字连接成功代替。
- 进入助手即优先填入旅行城市，手工编辑优先；每项默认第一条有效同城候选，可更换，不自动勾选、收藏或加入行程。最终收藏、清空和离开确认仍保留。
- 保留v3.0.1地图紧凑地点卡/地址补全、v3.0.2整批补城市、两行每日标题、原有旅行及费用功能；助手正文去掉重复旅行名称。
- 详细实现、协议和来源边界见[图片实施](v3.1.0-image-input-implementation.md)、[主线集成](v3.1.0-main-delivery.md)与[助手默认行为交付](v3.1.0-assistant-defaults-delivery.md)。上述文档中的未发布/未整合及手机阻塞属于当时阶段，不能替代本轮结果。
