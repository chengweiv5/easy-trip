## 实现

1. 只在助手向地图查询的边界补关键词。默认城市已确定为青州市时，首次请求使用“青州偶园／青州昭德古街／青州九龙峪景区／青州广福寺”，同时保留独立城市参数。
2. 名称已经包含城市短名、完整市名或省市前缀时不重复补；只改变实际查询关键词，原始名称、来源和编辑草稿不改。
3. 单项明确城市与默认城市冲突时，保留既有确认门禁；确认后使用该单项城市，不强行覆盖为默认城市。城市缺失仍等待补充，不借用手机定位猜测。
4. 首次、重试、单项修改后重查使用相同规则。没有自动重试、扩大城市范围、自动收藏或行程写入。
5. 通过 AppContainer → ViewModel → Controller 注入诊断器。每次记录开始及结束，区分成功、无坐标结果、城市不匹配、SDK 错误、超时、取消和其他错误；记录候选数量、同城有效候选数、耗时、数值错误码和是否补前缀。
6. 关键词和城市仅记录每个 Controller 随机盐生成的摘要，盐不落盘；随机诊断会话 ID、运行代次和 A–T 对应序号用于关联。同会话可判断重试参数是否变化，不支持跨会话关联或从日志反推出具体地点名。
7. 不记录原文、图片、地点名、城市明文、POI ID、地址、坐标、旅行 ID、Key、URL 或 SDK 原始异常。日志先输出 `EasyTripSearch` tag，再写本机受限缓存；异常或协作式超时不改变搜索结果及取消保护。
