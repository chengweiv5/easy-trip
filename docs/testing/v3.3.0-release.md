## 本版范围

相对 v3.2.0，新增已有旅行内的携程社区／小红书分享文案或 URL 粘贴。复用助手输入与地图候选、用户选择后手动收藏、成功后空白新一轮；不自动创建旅行或调整行程，不包含大众点评、系统分享扩展或语音。

- 一批一条链接，读取原文及原帖图片；最终地点最多30、图片最多20，独立体积限制仍在，超限明确失败，不静默截断。
- 根据作者证据合并同地别名、剔除单独食品及全部餐饮地点；保留住宿等非餐饮地点。普通手动输入范围不因此收窄。
- 区分作者编号／标签／路线点与底图背景名称，不简单按“村”字过滤；保留明确推荐的美术馆、花卉市场等目标。
- 古城与独立城门不强行合并；地图无法准确匹配时保留待核对。
- 登录／验证、删除、原图不齐等明确失败，不以分享标题冒充正文。图文发送至用户配置模型，可能收费；不应提交敏感资料，收藏前需检查。

实现与开发验收见 [粘贴链接](v3.3.0-paste-links-implementation.md)、[语义去重](v3.3.0-semantic-dedup.md)、[地图背景](v3.3.0-map-background.md)、[作者证据及30地点](v3.3.0-grounded-30.md)、[Git交付](v3.3.0-paste-links-git-delivery.md)。旧文档中的超限／保存／手机阻塞或未发布只代表其阶段，不代表当前发布状态。
