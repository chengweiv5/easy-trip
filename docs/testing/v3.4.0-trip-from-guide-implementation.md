## 2. 持久化、恢复与迁移

新增创建命令包含固定操作ID、旅行ID、元数据、最终选择和来源摘要，摘要覆盖全部提交内容。Room 同一事务写入旅行、空白日、收藏、旧导入回执和独立创建回执；同命令重试不重复创建，故障不留半成品。

schema11 的原 `assistant_import_receipts` 随旅行外键级联删除，无法区分“从未提交”与“提交后旅行被删除”。因此 **11→12 仅新增无旅行外键的 `assistant_trip_creation_receipts`**，不改原表、原摘要或原回执格式。旅行删除后保留独立回执，旧操作返回 Deleted，不复活旅行。所有原迁移继续接入。

私有 `no_backup` 下使用 AtomicFile 保存一个未决最终命令，不存凭据和图片。恢复先查回执：

- 已提交：清理已确认记录并在主线程进入旅行；清理／导航失败可显式重试，不再新建。
- 尚未提交：保留表单，不自动提交；核对后可修改，再创建一个新的操作。
- 已删除：明确提示，不重建。
- 无法核实／记录损坏：保留并锁定，允许重新核对，不覆盖未知操作。

新建确认页复核配置代次、授权和选择快照；不要求已经卸载的候选地图继续处于 ready。重建 Composition 不取消有效元数据任务；手动日期编辑优先于晚到结果。

**回滚只允许同签名、兼容 schema12 的前向修复，不能安装仅识别 schema11 的旧包来降级数据库。**
