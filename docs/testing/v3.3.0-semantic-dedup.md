## 实现

- `AssistantPlaceNormalizer`：一次模型工具调用输出已有候选ID的分组／丢弃；完整覆盖、无重复／越界ID、规范名必须来自组内、禁止跨城合并和新增字段。丢弃原因含`FOOD/DINING/BACKGROUND/NOT_PLACE`；来源合并保留。语义由模型判断，结构校验不能证明实体身份绝对正确。
- 链接素材每份提取100个、全批400个候选安全预算；之后才检查最终20地点上限。全部图文理解完成后再整理，部分失败不提前查询地图。
- 提取和整理两层均强调餐饮／食品排除、住宿保留、地图背景不当作目的地、每个query一个地点、独立景点不因包含关系强行合并。
- 图片提取不携带整篇正文，避免把正文复述成图中证据；图中文字来源须与query对应。手动图片原流程保留。
- 整理失败／取消后保留成功素材，同城市重试只发整理请求；默认城市变化时，依赖旧城市的提取缓存失效，重新理解但不重新下载。取消不发布未整理候选。
- 状态复用现有区域，按钮“正在处理笔记…”，进度“正在合并同一地点、剔除餐饮和非地点名称…”。无新页面、按钮、系统分享接收、语音、新旅行或排行程。
