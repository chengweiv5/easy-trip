## 根因与修复

### 首次进入即填默认搜索城市

此前只有点击“全部标记到地图”后的 `submit()` 才解析旅行名；打开助手时仅尝试地点池城市，空地点池的徐州旅行因此第一次显示空城市，搜索后城市才留在界面中。

现在由工作区在助手打开且地图授权有效时调用 `prepareDefaultCity()`：

1. 已有城市、手动编辑值优先保留。
2. 自动来源仍为地点池当前城市，其次旅行名中的唯一城市，复用既有解析器；**不使用手机所在地，也不硬编码徐州**。
3. 不需要输入地点、点击搜索或清空；徐州旅行首次打开即可自动获取并填入“徐州市”。
4. 获取中显示提示，不允许重复提交，但城市仍可手动编辑。未配置模型或地图尚未就绪不阻止旅行城市准备。
5. 解析最长 12 秒；城市未知、异常或超时保持空白并允许手填。取消、撤回授权、旅行失效、手动修改后拒绝旧异步结果覆盖。
6. 打开助手不会调用模型或搜索地点。提交时仍保留原有城市兜底。

### 每个地点默认采用第一条有效同城候选

- 保留坐标有效性、非空 ID/名称、去重及数量上限检查。
- 按地图搜索返回顺序采用第一条有效且城市一致的候选；后面的精确同名项不再抢占第一条。
- 没有同城候选仍要求核对，不静默采用外地或城市未知的候选。
- 聚焦地点后通过“更换地点”展开候选；显示“已采用”，可以切换到其他候选。
- 更换沿用原确认失效规则；默认采用不等于勾选收藏，不自动写入。收藏仍需显式确认。
