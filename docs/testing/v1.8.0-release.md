# v1.8.0 发布验证

2026-10-06 发布 [Easy Trip v1.8.0](https://github.com/chengweiv5/easy-trip/releases/tag/v1.8.0)，已回读确认是 Latest 正式版。

## 发布范围

- 进入行程默认选中设备本地日期对应的当天，日期范围外选第一天；浏览时保留手选，从旅行列表重新进入时重新计算。
- 明确提交搜索后返回地图，临时标记结果地点并收起抽屉；展开抽屉只覆盖地图，不改变地图视角。
- 移除行程日期栏重复的竖线。
- 搜索结果显示距我的直线距离，无有效定位或地点坐标时隐藏距离。
- 同城搜索地图使用独立蓝点、白环、光圈及“我的位置”标签；城市按行政身份判断，初次视野纳入当前位置，抽屉和手势不反复拉回视角。

本版没有调整搜索结果排序。本次发布操作未再修改应用功能、数据库或设计文件。README 保留 v1.6.0 截图来源声明，没有将历史截图标为新版。
