- 仅影响新识别候选；用户显式选择的类型，包括“其他”，保持不变。
- 旧／当前恢复记录里的显式类型保持，不回填已收藏地点、不覆盖已有备注。
- 没有新增页面或布局；未调用或修改 Pencil。
- schema、模型 prompt、协议与收藏幂等逻辑未改。版本仍为 3.4.0/build27/schema13，保留 100 地点／20 图／30 天、图片可选及一次收藏结束整批规则。
