## 范围与操作边界

- 用户要求规格完成后直接开发，无须再次设计审批；已有旅行的助手输入框接受完整分享文本或一个链接，首批仅携程社区笔记与小红书笔记。
- 没有新增页面、导入按钮、系统分享接收器、自动剪贴板读取、语音、新建旅行或自动排行程。仅输入占位、隐私说明、读取进度与图片数量文案变化。
- 点击“全部标记到地图”才联网。链接正文和原帖配图取得并校验后再调用现有模型/地图流程；输入框保留原分享文案。模型不负责访问链接。
- 每批最多20图，链接与用户已选图片合计；单图10MiB、总计30MiB、准备后单图4MiB及像素保护不变。按张下载、解码、理解，不同时保留20张解码位图。超限明确失败，不静默截断。
- 相同地点名称/城市/核对状态合并来源后再计算20地点上限；不同别名仍以地图POI身份去重。只有用户点击收藏才写地点池，成功后清空本批并只删除旧图片ID。
- 开发版本3.3.0/build26/schema11；未提交、推送、建标签、发布Release或安装真实手机。保留上游默认城市、请求节流与抽屉相机行为。

## 实现

- `AssistantLinkInput`：从分享文本中识别URL、保留用户补充说明、拒绝多链接/不支持平台/凭据/非HTTPS；最终笔记身份再次核对。
- `AndroidAssistantLinkReader`：默认UA，本机WebView正常打开网页，只读DOM；携程先正常访问首页并等待初始化，再打开原始链接。小红书的可选App唤起仅阻止，不把它当作公开网页读取失败。
- `DefaultAssistantLinkLoader`：HTTPS白名单图片下载、大小限制、公共地址DNS检查、逐图完整准备；下载/解码失败及取消回滚新增文件，不动用户已有附件。
- `PlaceAssistantController`：读取阶段代次校验、进度、取消及晚到丢弃；读取完成缓存素材，模型失败只重试失败项，不重复抓链接；修改输入失效旧链接素材，清空/收藏新轮失效旧状态。
- 文本和图片解析器均接收最大20,000字提取素材；用户输入框仍最多2,000字，原图片模型单次请求超时不变。整批预算随图片数增长，上限30分钟。
- 生产源无URL参数、正文、图片或凭据日志；可注入诊断默认关闭。仪器测试的正文/截图仅含测试素材，留在隔离模拟器与本机证据目录。

## 已知边界

- 第三方页面可能变化或要求登录/验证，届时保留输入并提示重试/使用文字图片；不保证所有平台笔记永久可读。
- 无配图或无法确认张数/原帖结构的笔记保守拒绝；视频、店铺/订单/酒店、大众点评不接入。
- WebView使用应用级一方CookieManager，不是独立浏览器进程。图片下载有DNS公共地址检查；WebView导航/子资源采用域名与HTTPS限制，DNS和重定向由系统栈处理，不宣称逐跳DNS固定或网络沙箱。
- 未对用户真实模型进行识别计费调用；未实测真实高德与链接素材联合端到端、真实手机、系统相册、TalkBack/API26、线上20图帖子或全部帖子形态。
- 用户提供的小红书示例自身含较多景点/餐饮/住宿，真实模型可能识别超过20个地点；该上限未被本次20图要求放宽，产品会明确提示分批而非自动截断。
- 历史全应用UI/280dp等缺口沿用既有记录；不以助手专项宣称全应用UI全绿。
