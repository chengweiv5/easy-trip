## 行为

1. 一份正文／图片失败，不再阻止其他成功素材进入作者证据校验、餐饮过滤、语义整理和地图匹配。单份素材内部仍不接受未经校验的部分模型输出。
2. 失败／取消素材单独列出；手动重试只重新识别这些素材。同一城市上下文的成功识别结果从缓存复用，跨素材合并去重仍可能再次调用模型并产生费用。
3. 增量整理通过本地素材身份关联既有结果，保留行ID、用户修改的名称／城市／分类、POI及选择；只查询真正新增的结果，最终仍按POI去重。身份来自本地候选而非模型任意字段。
4. 部分收藏采用独立的 `guide-partial:` 幂等回执，不触发原 `guide:` 回执的攻略完成事务；已收藏行不可重复收藏，原攻略、成功缓存和失败素材仍保留。全部处理完成后收藏，才沿用清空新一轮。
5. 整理失败／取消／超限时保留此前可用结果，新增“重试地点整理”，不重复识别已完成图片。全部素材失败时没有可标记结果，并保留具体失败原因，包含100候选超限原因。
6. 攻略导入恢复记录兼容旧version 1，新增可选素材进度、成功／失败提取、待整理状态、素材身份及提取城市。取消时即时同步，不依赖已失效generation的finally。输入／图片变化清除旧缓存；默认城市修改后重开，不把旧城市缓存误当成新城市。
