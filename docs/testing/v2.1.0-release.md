# v2.1.0 发布验证

状态：发布候选（2026-10-10）。尚未创建 Release；完成构建、推送与公开回拉后补齐实际结果。

## 本版变化

- 花费总览、历年、年度、月份与类别等页面强化浅底、卡片、图标标题与间距分区。
- 年份／月份导航统一为紧凑周期控件，保留明确的当前范围与前后切换。
- 花费占比进度统一复用旅行设置的连续圆角样式，不再分段。
- 编辑地点分为时间安排、本次安排花费、地点备注；多笔费用的类别、金额、备注与操作层级更明确。
- 保存／取消固定在底部，真实键盘弹出时仍可操作；保留草稿、失败重试、取消确认、移除撤销及统一保存事务。

## 版本与构建

目标为 2.1.0 / versionCode17，Room schema9 不变，无数据库迁移或数据清理。本次比此前安装的 build16 递增构建号；签名必须与 v2.0.0 保持一致。从准确提交的干净隔离目录构建，不隐藏主工作区未跟踪证据，不改写 SOURCE_STATE。

## 开发验证与边界

提交前已核对前轮已测生产源码 SHA256 一致。前轮 955 JVM、42 费用设备、16 分区／时间 UI、71 日期事务通过，5 主题、320dp／2倍字号与真实键盘已覆盖。证据与细节见 [实现验证](v2.1.0-implementation.md)。分组结果不作为全应用用例总数。

既有 UI 验收缺口继续保留：v2.0 的8项 UI、22项旧时间轴，以及旅行列表窄屏大字体问题；本次不宣称全应用 UI 全绿。地图搜索／定位／路线完整端到端不是本轮范围。本轮不操作用户手机。

## 升级与回滚

正式版用户应同签名覆盖升级，不卸载、不清空数据；当前无完整数据导出或云端恢复。已安装 2.1.0/build16 的提前体验用户可手动下载 build17 覆盖安装；现有应用内更新按 versionName 比较，不会提示同名构建更新。问题使用同签名、递增 versionCode 的向前修复版，不直接降级旧 schema 应用。

不移动／删除既有标签，不覆盖正式附件。代码变更可通过审阅后的逆向提交撤销；只撤销文档或设计元数据时保留后续修改，设计必须通过 Pencil MCP。
