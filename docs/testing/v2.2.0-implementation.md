## 实现

1. **数字显示**
   - 金额、数量和已舍入的公里数使用逗号千分位。示例：`¥12,345.60`、`1,234 个地点`、`1,234.6 公里`。
   - 旅行、行程/日历、花费回顾及月柱图、内联费用摘要、地点/搜索、分享和影响确认展示同步。
   - 不改变原小数位规则。日期、年份、时间、序号、ID、编辑输入和金额解析不变；存储和计算仍使用原数值。
2. **空旅行初始城市**
   - 仅创建成功后的首次工作台入口触发；普通打开、返回后重开不触发。
   - 等待数据就绪且无收藏，通过已授权高德SDK行政区目录按名称出现顺序匹配首个明确城市，优先较长城市名，歧义不猜测。覆盖行政目录中的市/县级市；未识别地名保持默认。
   - 获取行政边界后按包围盒请求城市视野；边界缺失时使用中心点和zoom11。查询整体12秒超时；失败静默保留默认视野，不自动创建收藏。
   - 已有/查询期间新增的收藏、用户地图手势、搜索、定位、缩放或主动切换视角优先，不被迟到城市结果覆盖。无有效地图授权不发起查询。
3. **旅行列表**
   - 主卡、其他旅行标题和所有旅行置于同一`LazyColumn`，消除小局部滚动窗口。
   - 页头/筛选、创建按钮、导航固定；切换待出行/已出行回到列表顶部。保留菜单、创建和空状态等交互。
