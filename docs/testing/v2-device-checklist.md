```bash
./gradlew clean test lint assembleDebug
ANDROID_SERIAL=<easy_trip_p60pro serial> ./gradlew connectedDebugAndroidTest
```

运行 instrumentation 前必须通过：

```bash
adb -s <serial> emu avd name
```

确认输出严格为 `easy_trip_p60pro`，不得使用其他模拟器或物理真机。
