## 本版变化

相对正式版 v3.1.0，包含此前已推送的精简助手、城市与节流、收藏后新一轮，以及本轮抽屉相机修复：

- 左侧选择／全选后一次收藏，去掉核对、二次确认和回执中转。保存中锁定，失败保留选择与幂等重试。
- 成功收藏后清空本批全部候选、文字、图片及焦点，开始新一轮；保留旅行、城市和已收藏地点。旧查询和旧图片清理不能覆盖新一轮。
- 搜索框与助手共用旅行名＋定位默认城市规则：用户指定优先；单城固定；多城定位命中取定位城，否则标题首城；无城市名定位兜底。地图城市逻辑不变。
- 首次和重试 POI 查询都带城市；助手共享 700ms 发起间隔与最多 2 个在途请求，减少突发限流风险，不自动重试、不保证所有 SDK1800 都消失。
- 收藏底栏去独立白底，全选框与文案间距 8dp，保持整组点击区。
- 助手打开／关闭／重开和三档拖动不重置地图中心缩放，清空不重放旧视野；新结果、主动选点和普通搜索仍能定位。地点池／行程自身原有规则保留。

详细证据见 [助手精简](v3.2.0-assistant-simplify-implementation.md)、[统一城市](unified-search-city.md)、[节流修复](v3.2.0-assistant-search-pacing-fix.md)、[自动新一轮](assistant-next-round.md)、[抽屉相机](assistant-drawer-camera.md)。旧文档的未提交／未发布属于其开发阶段，不代表本轮状态。
